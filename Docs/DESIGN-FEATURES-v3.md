# 기능 추가 설계안 v3

작성: 2026-11-07. **검토용입니다. 승인 전에는 구현하지 않습니다.** 수치는 전부 임시값이고 데이터 에셋에만 둡니다.

순서는 1 멀티, 2 방어탑, 3 사령부 단계, 4 지뢰, 5 청룡 공화국입니다.

## 1. 멀티 (확장 기지)

### 규칙

- 공병이 사령부를 추가로 짓습니다. 시작 사령부와 같은 건물입니다.
- 공병 생산, 철·목재 반입, 인구 +10, 전기 저장 +200을 그대로 가집니다.
- 휴전 중에는 본진 안에만 짓습니다. 지금의 `IsReachable` 검사가 그대로 적용됩니다.

### 임시값

| 항목 | 값 | 근거 |
| --- | --- | --- |
| 비용 | 철 400, 목재 300 | 제시안 유지. 시작 자원의 약 1배라 초반에는 부담됩니다 |
| 건설 시간 | 60초 | 제시안 유지. 집하장(15초)보다 훨씬 깁니다 |
| 체력 | 3,000 | 시작 사령부와 같음. 건설 중에는 부지 체력 규칙을 따릅니다 |
| 해금 | 사령부 1채 이상 완공 | 단계 업그레이드를 넣으면 1단계부터 가능 |

### 패배 조건

**지금 규칙과 맞습니다. 코드 변경이 필요 없습니다.** `VictorySystem`은 완공된 `IsCoreBuilding` 건물이 하나라도 있으면 생존으로 봅니다. 시작 사령부를 잃어도 확장 사령부가 있으면 삽니다. 짓는 중인 사령부는 세지 않습니다.

### 고칠 곳

- 사령부 비용·건설 시간이 지금 0입니다. 값을 넣어도 시작 사령부는 `CreateFinishedBuilding`으로 만들어져 영향이 없습니다.
- **수리비:** 지금 사령부는 비용이 0이라 수리가 무료입니다(확정 사항 13). 비용을 넣으면 사령부 수리비가 생깁니다. 무료를 유지하려면 수리 전용 예외가 필요합니다(질문 1).
- `FactionSpec.Buildings`에 사령부를 넣습니다.
- **HUD 패널이 넘칩니다.** 공병 건설 패널은 10칸인데 건물이 11개가 됩니다. 방어탑까지 나누면 12개입니다. 페이지 넘김이 필요합니다.

### AI 판단 규칙 (7분 뒤)

매 판단에서 확장을 고려할 때 아래 순서로 봅니다.

| 순서 | 조건 | 짓는 것 |
| --- | --- | --- |
| 1 | 일하는 노드가 반입 지점에서 30 이내 | 짓지 않음 |
| 2 | 노드 주변 25 안의 남은 매장량이 5,000 이상이고, 철 800·목재 500 이상 있고, 사령부가 `MaxHeadquarters` 미만 | 사령부 |
| 3 | 인구 여유가 4 미만이고 위 비용이 있음 | 사령부 |
| 4 | 그 외 | 집하장 |

**이유:** 큰 자원에는 공병을 현지에서 뽑는 사령부가 낫고, 작은 자원에는 목재 150짜리 집하장으로 충분합니다. 앞마당(철 3,000 + 숲 4,000)은 사령부, 숲 확장(8,000 + 2,000)도 사령부, 작은 잔여 노드는 집하장이 됩니다.

## 2. 방어탑 2종

기존 방어탑을 둘로 나눕니다. 공통: 건설 20초, 체력 700, 상시 유지비 0.5, 정전 시 공격 간격 x2.

| 항목 | 지상 방어탑 | 방공포대 |
| --- | --- | --- |
| ID | `*_ground_tower` | `*_air_defense` |
| 공격 | 대장갑, 지상만 | 대공, 공중만 |
| 피해 | 40 | 30 (공중 x1.5 = 45) |
| 사거리 | 10 | 14 |
| 공격 간격 | 1.5초 | 1.5초 |
| 비용 | 철 250, 목재 100, 전기 100 | 철 200, 목재 100, 강철 30, 전기 100 |
| 해금 | 병영 + 발전소 | 병영 + 발전소 |

**주의:** 지금 방어탑은 저공 비행 유닛(호크)을 맞힙니다. 대장갑 무기 예외 규칙 때문입니다. "지상만 공격"이 되려면 건물 무기에 지상 전용 표시를 추가합니다. 대공 무기는 이미 공중만 맞힙니다.

## 3. 사령부 단계 업그레이드

### 규칙

- 사령부 건물마다 단계(1~3)를 가집니다. 플레이어의 단계는 **완공된 사령부 중 가장 높은 값**입니다.
- 업그레이드 중에도 공병 생산, 반입, 인구, 전기 저장이 그대로 동작합니다. 공병 대기열과 별도 타이머를 씁니다.
- 비용은 시작할 때 전부 내고, 취소하면 환불합니다(기존 방식).
- 단계가 높은 사령부를 잃으면 단계가 내려갑니다. "파괴되면 다시 잠김. 진행 중인 생산은 유지" 규칙과 같습니다.
- 전기 0이면 업그레이드 타이머가 멈춥니다. 사령부의 다른 기능은 멈추지 않습니다.

| 단계 | 조건 | 비용 | 시간 | 해금 |
| --- | --- | --- | --- | --- |
| 2단계 | 발전소 + 가공소 | 철 400, 강철 100, 전기 150 | 45초 | 군수공장, 비행장, 연구소 상위 연구 |
| 3단계 | 2단계 + 군수공장 + 연구소 | 철 600, 강철 250, 전기 300 | 60초 | 중공업 기지, 대형 유닛, 상위 모듈 |

### 해금 트리

조건 "2단계"·"3단계"는 사령부 단계입니다. 굵게 쓴 곳이 지금과 달라지는 부분입니다.

| 건물·유닛 | 지금 조건 | 새 조건 |
| --- | --- | --- |
| 발전소, 보급창, 병영, 집하장 | 사령부 | 사령부 |
| 사령부 (추가) | 없음 | **사령부** |
| 가공소 | 발전소 | 발전소 |
| 연구소 | 발전소 | 발전소 |
| 지상 방어탑, 방공포대 | 병영 + 발전소 | 병영 + 발전소 |
| 군수공장 | 병영 + 발전소 | 병영 + 발전소 + **2단계** |
| 비행장 | 군수공장 + 가공소 | 군수공장 + 가공소 + **2단계** |
| 중공업 기지 | 군수공장 + 연구소 + 가공소 | 군수공장 + 연구소 + 가공소 + **3단계** |
| 스카이포트리스 폭격기 | 비행장 | 비행장 + **3단계** |
| 만리 다연장포 | 중공업 기지 | 중공업 기지 (이미 3단계) |

```text
1단계 사령부
├─ 발전소 ─┬─ 가공소 ─────────────┐
│          └─ 연구소              │
├─ 병영 ── 방어탑 2종 (병영+발전소) │
├─ 보급창, 집하장                  │
└─ [2단계: 발전소 + 가공소] ◄──────┘
    ├─ 군수공장 (병영+발전소)
    │   └─ 비행장 (+가공소)
    ├─ 연구소 상위 연구
    └─ [3단계: 군수공장 + 연구소]
        ├─ 중공업 기지 ── 대형 지상 유닛
        ├─ 대형 공중 유닛 (비행장에서)
        └─ 상위 모듈
```

**필요한 구조:** 유닛별 단계 조건입니다. 스카이포트리스가 비행장 생산이라 건물 조건만으로는 막을 수 없습니다. `BuildingSpec`, `UnitSpec`, `ModuleSpec`에 `RequiredHqLevel`을 둡니다.

### 연구소 공격력·방어력

**연구 자체가 아직 없습니다.** ROADMAP은 챕터 5의 일로 둡니다. 다만 `UpkeepMode.WhileResearching` 자리는 이미 있어서 유지비와 정전은 그대로 연결됩니다.

**구분 제안: 지상·공중.** 소형·중형·대형으로 나누면 연구가 9개로 늘고, 소형 물량(대륙)이 불리해집니다.

| 연구 | 1단계 | 2단계 | 3단계 |
| --- | --- | --- | --- |
| 지상 공격력 | +10% | +20% | +30% |
| 지상 방어력 | -10% 받는 피해 | -20% | -30% |
| 공중 공격력 | +10% | +20% | +30% |
| 공중 방어력 | -10% | -20% | -30% |
| 필요 단계 | 사령부 1 | 사령부 2 | 사령부 3 |
| 비용 | 강철 100, 전기 100 | 강철 200, 전기 200 | 강철 400, 전기 300 |
| 시간 | 45초 | 60초 | 90초 |

곱셈이라 피해 공식 한 곳(`DamageUnit`)에 넣습니다. FP 값이고 결정론 영향은 없습니다.

### 도달 시각 목표

휴전 7분, 경기 10~15분 기준입니다.

| 시각 | 목표 | 근거 |
| --- | --- | --- |
| 1:00 | 병영, 보급창 | 현재 AI 측정 0:50 |
| 2:00 | 가공소 | 현재 1:50 |
| 3:30~4:30 | **2단계 시작** | 강철 100이 쌓이는 시점. 가공소 완성 뒤 약 100초 |
| 5:00 | 군수공장 | 현재 3:20이던 것을 2단계 뒤로 늦춤 |
| 6:30~7:30 | **3단계 시작** | 휴전 끝 무렵. 강철 250 필요 |
| 8:30~9:30 | 중공업 기지, 첫 대형 유닛 | 다리가 열린 뒤 첫 교전 다음 |
| 12:00~ | 지상 공격력 3단계 | 후반 |

**효과:** 지금은 군수공장이 3분대라 설계 2장의 "전쟁 준비 5~9분"보다 빠릅니다. 단계 조건이 이 시간표를 설계에 맞춥니다.

## 4. 대륙 연방 지뢰

### 규칙

| 항목 | 대인 지뢰 | 대전차 지뢰 |
| --- | --- | --- |
| 비용 | 철 40 | 철 60, 강철 10 |
| 매설 시간 | 3초 | 5초 |
| 반응 대상 | 공병, 소형 | 중형, 대형 지상 |
| 피해 | 소형 120, 범위 2.5 | 중형·대형 350, 범위 2 |
| 반응 범위 | 1.5 | 2 |
| 체력 | 40 | 60 |

- **공중 유닛에는 반응하지 않습니다.**
- **매설 상한:** 플레이어당 합계 20개입니다.
- **활성화:** 매설 후 3초 뒤에 작동합니다. 공병 자신이 밟는 일을 막습니다.
- **휴전 중:** 자기 본진 안에만 묻습니다. 휴전 중에는 터지지 않습니다.
- **금지 위치:** 다리 위와 건설 금지 구역입니다. 길목을 지뢰로 봉쇄하지 못하게 하되, 협곡 안 허용 여부는 질문 4입니다.
- **아군·동맹:** 주인과 동맹, 파기 유예 중인 상대는 밟아도 터지지 않고 볼 수 있습니다.
- **파기 후:** 지뢰는 주인에게 남습니다. 파기 유예 10초가 끝나면 옛 동맹에게도 터지고, 옛 동맹의 시야에서 사라집니다.
- **패배한 플레이어의 지뢰:** 패배 시 전부 제거합니다.

### 은폐·탐지

- 시뮬레이션: 지뢰에 `RevealedMask`(플레이어별 비트)와 탐지 범위만 둡니다. 0.5초마다 다시 계산합니다.
- 화면: 내 자리의 비트가 꺼져 있으면 그리지 않습니다.
- 공격 판정: 비트가 켜진 플레이어만 조준할 수 있습니다. **AI도 이 비트만 봅니다.**

**한계 (보고서에도 적음):** 동기화 방식상 모든 기기가 전체 상태를 가집니다. 지뢰 위치도 메모리에 있습니다. 숨기는 것은 화면뿐이라, 메모리를 읽는 조작 도구에는 무력합니다. 서버 권한 방식이 아닌 이상 막을 수 없습니다. 방 코드 친선 대전 중심의 MVP라 수용 가능한 수준으로 판단합니다.

**지금 게임에는 시야(전장의 안개)가 없습니다.** GDD의 "시야 공유"는 아직 구현 전입니다. 탐지는 시야와 별개로 "범위 안의 지뢰"만 다룹니다.

### 탐지 수단

| 수단 | 범위 |
| --- | --- |
| 공병 | 5 |
| 사령부 | 12 |
| 방어탑 2종 | 10 |
| 자유 연방 정찰 레이더 모듈 | 10 (이동 탐지) |
| 위성 연계 모듈 | 정찰 레이더 범위 +30% |

정찰 레이더와 위성 연계는 챕터 5 모듈입니다. 그 전에는 자유 연방의 이동 탐지 수단이 공병뿐이라 불리합니다(질문 5).

### 결정론

- `MineSystem`이 틱마다 지뢰를 **엔티티 번호 순**으로 처리합니다. Quantum 필터 순서는 결정적입니다.
- 한 틱의 처리: 활성화 타이머 → 대상 검사 → 폭발.
- **같은 틱에 여러 지뢰가 터지면:** 앞 지뢰가 유닛을 파괴하면 뒤 지뢰는 다음 틱 대상에서 뺍니다. 각 지뢰는 그 틱 시작 시점의 위치로 판정합니다.
- **연쇄 폭발 없음:** 폭발 피해는 다른 지뢰에 주지 않습니다.
- 소수점은 전부 FP입니다.

### AI

- 대륙 AI는 휴전 중 다리 안쪽에 대인 지뢰 4개, 대전차 지뢰 4개를 묻습니다.
- 다리가 열린 뒤에는 확장 입구에 묻습니다.
- 자유 AI는 공병을 앞세우지 않습니다. 지뢰로 잃은 유닛을 세어 대응하는 규칙은 2차로 둡니다.

## 5. 청룡 공화국

GDD에 이미 있는 진영입니다. 컨셉 "기갑·네트워크, 빠른 성장", 강점 "연구·업그레이드 속도, 기갑", 약점 "자원 소모가 큼", 패시브 "고속 연구: 연구·모듈 개발 시간 -25%"입니다. 대표 유닛 세 종도 GDD 이름을 그대로 씁니다.

| 유닛 | 크기 | 비용 | 생산 | 체력 | 공격 | 피해·간격 | 사거리 | 특수 기능 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 공병 | 공병 | 철 110 | 11초 | 80 | 없음 | | | 작업 |

| 경장갑 정찰차 | 소형 | 철 90, 목재 70, 전기 20 | 18초 | 130 | 대공·대인 약함 | 12 / 1초 | 7 | 빠른 이동 |

- **약점 표현:** 같은 등급보다 비용이 10~15% 비쌉니다. 소형 체력은 낮습니다.
- **`경장갑 정찰차`와 `돌격 장갑차`는 제안 이름입니다.** GDD에는 세 종만 있어 6종을 채우려고 만들었습니다.
- **새 기능 3개:** 데이터 링크는 시야가 없으면 의미가 없습니다. 기동 사격은 이 게임에 이동 중 패널티가 없어 효과가 없습니다. 능동 방어는 투사체 개념이 없어 "일정 간격 피해 1회 무효"로 바꿔야 합니다(질문 7).
- **패시브 의존:** "연구·모듈 개발 -25%"는 연구가 있어야 동작합니다. 3번 항목이 먼저입니다.
