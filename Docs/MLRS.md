# 다연장 로켓 포대

자유 연방과 대륙 연방에 각각 건설 항목을 추가했다. 2단계 기지와 완공된 군수공장이 필요하다. 공병으로 짓는 동안 기존 건설 단계와 점유 규칙이 적용되며, 파괴하면 점유와 Unity 기초판이 함께 사라진다.

| 설정 | 기본값 |
| --- | --- |
| 건설 비용 | 철 480, 목재 100, 강철 160, 전기 160 |
| 건설 시간 및 체력 | 35초, 1,400 |
| 최대 탄약 및 발사 간격 | 12발, 0.8초 |
| 재장전 | 25초. 사령부 3단계에서는 20초 |
| 교전 거리 및 조준 | 8–45m, 새 표적에 1초 조준 |
| 로켓 및 피해 | 비행 속도 설정 26m/s, 호 높이 7m, 중심 피해 42, 반경 3.5m 가장자리 피해 35% |
| 유지비 및 시야 | 전기 초당 1.5, 포대 자체 시야 16m |

Quantum은 먼저 아군 건물을 공격 중인 적, 그다음 기갑, 그다음 거리가 가까운 유효 지상 표적을 고른다. 조건이 같으면 개체 인덱스로 순서를 정한다. 사거리와 Quantum 시야를 계속 적용하며 유효한 표적은 유지한다. 로켓은 발사 시 기록한 착탄 지점으로 비행한다. 이동한 목표는 폭발 반경을 벗어나 피할 수 있다. 탄창이 비면 표적 변경과 관계없이 재장전하고, 정전과 EMP 동안 진행을 멈춘다. 포대가 파괴되면 새 발사는 종료되며 비행 중인 로켓은 착탄까지 유지된다.

Unity는 확정 발사·착탄 이벤트에서 화염, 연기, War FX, 소리와 화면 흔들림을 재생한다. 회전식 포탑, 좌우 6문 발사관, 탄약고 해치는 Quantum 상태를 읽는다. 민간 작업자의 점검·휴식은 같은 기지 작업자 시스템의 View 연출이다. 선택 패널은 체력, 탄약, 최소·최대 사거리, 작동 상태와 재장전 진행률을 표시한다.

| 파일 | 역할 |
| --- | --- |
| `Assets/QuantumUser/Simulation/FactoryWars/Systems/MlrsSystem.cs` | 자동 조준, 연속 발사, 정전·재장전, 투사체 비행 |
| `Assets/QuantumUser/Simulation/FactoryWars/FactoryWars.qtn` | 탄창 및 로켓 컴포넌트와 확정 이벤트 |
| `Assets/QuantumUser/Resources/FactoryWars/{ff,cf}_mlrs_battery.asset` | 양 진영 건설 설정과 12개 포구 좌표 |
| `Assets/Art/Generated/Prefabs/MLRS_Battery.prefab` | 공유 포대 프리팹과 정비 동선 포인트 |
| `Assets/QuantumUser/View/FactoryWars/Battle/MlrsVisual.cs` | 포탑 및 탄약고 해치, 로켓 렌더링 |
| `Assets/Tests/MlrsTests.cs` | 로컬 경기, Photon 실서버, GPU 캡처 테스트 |

포대와 비행 로켓 메시는 프로젝트의 공유 팔레트로 제작했다. 기존 War FX와 Synty 작업자 연결을 활용했다. 새 판매용 팩 파일은 추가하지 않았다. Unity에서 **Tools → Factory Wars → Build MLRS Data**를 실행하면 포대 데이터와 프리팹만 갱신된다.

## 검증 결과

- Unity 6000.0.85f2의 GPU PlayMode 집중 검사 10건이 모두 통과했다. 포대 건설·비용·기초판·점유·선택 HUD, 전장의 안개, 기갑 우선과 표적 교체, 파괴 후 발사 정지, 범위 피해와 탄약, 25초 재장전 후 자동 발사, 3단계 재장전 20초, 포대 두 기 동시 발사를 검증했다.
- Photon 실서버의 두 클라이언트에서 비행·착탄과 체력 감소를 확인했다. 동일 확정 프레임 체크섬 22개가 일치했고 오류는 0건이었다.
- 한국어 HUD에서 상태와 탄약·사거리를 확인했다. GPU 캡처 10장은 1280×720으로 렌더링하고 검수했다. [스크린샷](status_images/MLRS/)
- Android 기기가 연결되어 있지 않아 프레임 시간, 발열과 터치 조작은 미검증이다. 로켓 메시 48개, 연기 경로 12개, War FX 착탄 풀 8개로 화면 부하를 제한했다.
- 당시의 집중 결과는 이전 전체 PlayMode 기준선과 별개다. [이전 전체 PlayMode 결과](FactoryWars_PlayMode_2026-11-21.md)
