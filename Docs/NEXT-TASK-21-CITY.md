# 항목 21 — 도시 전장 (파괴되는 도시 건물, 진지 건물, 닫힌 맵)

시작 조건: 항목 20을 끝내고(테스트 전부 통과) push한 뒤, 그래픽 탐색(19A)보다 **먼저** 한다.
CLAUDE.md 규칙과 결정론 유지(시뮬레이션에 float·Mathf·Random 금지), 전체 테스트 통과 필수. 단계마다 커밋·push.
수치는 데이터 에셋에만 두고 임시값 표에 모은다.

## 사용자 요청
1. 전장이 초원이 아니라 **도시**다.
2. 도시 건물은 체력이 있고, 체력이 0이 되면 **붕괴**한다.
3. 일부 도시 건물은 스타크래프트 벙커처럼 **보병이 들어가 안에서 공격**할 수 있다.
4. 맵은 광활하게 끝없이 이어지는 모습이 아니라 **경계가 딱 정해진 공간**이다.

## 1. 맵: 항목 17의 전략 구조는 유지하고 도시로 바꾼다
세 갈래 길, 성격이 다른 앞마당 2곳, 공유 확장, 중앙, 뒷길, 고지대, 대칭, 이동 시간 목표는 그대로다. 겉모습과 판정 요소만 바꾼다.

| 항목 17 요소 | 도시 버전 |
| --- | --- |
| 초원 바닥 | 아스팔트 도로, 보도, 광장, 공터(흙·잔디 조금) |
| 능선·언덕(통과 불가) | 파괴 불가 고층 건물 블록, 고가도로 교각, 높은 담 |
| 협곡 | 좁은 골목(폭 8~10m), 양옆은 건물 |
| 고지대 + 비탈길 | 주차장 건물 옥상, 고가 광장 + 경사로. 판정은 기존 고지대 규칙 |
| 강 + 다리 | 도시 운하(콘크리트 제방) + 다리. 휴전 울타리 구조 유지 |
| 여울 | 얕은 배수로·물 고인 지하차도(감속 구역) |
| 도로 | 큰길(속도 +10%) |
| 숲(목재) | 도시 공원·가로수 숲. 채집 규칙은 같다 |
| 철광산 | 고철 하치장·광석 적치장. 채집 규칙은 같다 |
| 점령지 | 방송국(중앙 통신소), 변전소(발전 중계소) |
| 뒷길 바리케이드 | 버스·트럭 잔해와 콘크리트 블록 더미 |
| 본진 | 운하로 둘러싼 공업 지구(공장 부지). 건설 가능 면적과 수용 25채 이상은 유지 |

- 2인 240, 4인 320 크기를 유지한다(사용자: 넓은 쪽이 좋음, 줄이지 말 것). 도시 건물이 생기면 길이 바뀌므로 이동 시간을 다시 재서 목표(중앙 45~60초 등)를 맞춘다.
- 도시 건물 배치도 2인은 점대칭, 4인은 90도 대칭이다.

## 2. 도시 건물 (CityBuilding)
- 중립 엔티티. 종류는 데이터로 정의한다.
  - 소형: 상가·주택, 체력 1,500
  - 중형: 아파트·사무실, 체력 3,000
  - 대형: 창고·공장, 체력 5,000
  - 수치는 모두 임시값
- 장갑 유형은 건물. 자동 조준 대상이 아니다. 지정 공격과 범위 피해(포격·폭격·폭발)로만 깎인다.
  - 다연장·폭격기는 도시 건물에 피해 ×1.5
- 손상 단계: 100~60% 멀쩡함, 60~30% 금 가고 연기, 30~0% 일부 무너지고 불. 0이면 붕괴한다.
- **붕괴 결과**
  - 건물 자리가 **잔해 구역**이 되어 통과할 수 있게 된다. 이동 속도 -30%(여울과 같은 방식).
  - 건물마다 별도 NavMesh 영역을 두고 붕괴 시 연다. 바리케이드와 같은 방식이다.
  - 영역 수 한도(보고서상 512)를 넘지 않게 맵당 파괴 가능 건물 수를 정하고 기록한다. 목표는 2인 40~60채, 4인 80~120채.
  - 붕괴하면 주변 반경 6m에 붕괴 피해 200(임시값). 건물 안 진지 병력은 밖으로 튀어나오며 최대 체력의 25% 피해를 입는다.
  - 붕괴는 되돌릴 수 없다. 이벤트 CityBuildingDamaged(단계 변화), CityBuildingCollapsed.
- 맵 테두리와 큰 블록 일부는 **파괴 불가 랜드마크**로 둬서, 붕괴가 쌓여도 맵 구조가 완전히 열리지 않게 한다.
- **전략 목적**
  - 건물을 부숴 지름길을 내거나 진지를 없앤다.
  - 반대로 길목 건물을 남겨 방어한다.
  - 처음부터 막혀 있는 지름길이 뒷길 바리케이드 말고도 몇 곳 생긴다(대칭으로).


## 2-1. 옆으로 쓰러지는 건물 (일부 타입만, 사용자 지정)
붕괴 방식은 두 가지다. 대부분은 2번처럼 제자리에서 무너져 길이 **열린다**. **일부 타입만** 옆으로 쓰러져 길을 **막는다**.
- **쓰러지는 타입:** 키가 크고 좁은 건물만. 고층 사무 빌딩, 급수탑, 공장 굴뚝, 송신탑. 데이터에 `Topples: true`와 쓰러지는 방향을 둔다.
  - 수량: 2인 6~10채, 4인 12~20채. 대칭.
- **방향은 맵 데이터에 고정한다.** 공격 방향에 따라 바뀌지 않는다. 플레이어가 미리 읽고 계획할 수 있어야 하기 때문이다.
- **쓰러지는 자리(낙하 구역):** 건물 높이만큼 그 방향으로 뻗은 사각형. 보통 옆 도로나 골목을 가로지른다.
  - 붕괴 전: 통과 가능. 건설 금지 구역이다.
  - 붕괴 후: **통과 불가가 된다.** 원래 건물 자리는 잔해(통과 가능, -30%)로 열린다. 한 길을 열고 다른 길을 막는 셈이다.
  - NavMesh는 건물 자리와 낙하 구역을 각각 별도 영역으로 굽고, 붕괴 때 하나는 열고 하나는 닫는다. 영역 수 한도 계산에 포함한다.
- **붕괴 순간**
  - 낙하 구역 안의 지상 유닛은 피해 600(임시값)을 입고, 가장 가까운 통과 가능 지점으로 밀려난다. 결정론적으로 정한 순서와 위치로.
  - 낙하 구역 안 플레이어 건물은 생길 수 없다(건설 금지).
  - 이벤트 CityBuildingToppled(건물, 방향).
- **예고:** 체력 30% 이하가 되면 건물이 그 방향으로 살짝 기울고, 바닥에 낙하 구역이 붉은 빗금으로 보인다(아군·적군 모두). 유닛이 깔리지 않게 피할 시간을 준다.
- **안전 규칙(테스트로 보장)**
  - 낙하 구역은 다리, 본진 입구, 앞마당 유일 입구, 맵 경계 출구를 막지 않는다.
  - **쓰러지는 건물이 전부 쓰러진 경우를 포함해 모든 조합에서**, 모든 본진과 모든 앞마당·점령지가 서로 지상으로 이어져 있어야 한다. 전체 조합이 많으면 "전부 쓰러짐 + 하나씩만 쓰러짐"과 무작위 200조합을 검사한다.
- **전략 용도:** 적이 자주 쓰는 길목 옆 빌딩을 쓰러뜨려 길을 끊거나, 내 앞마당으로 오는 측면 길을 막는다. 대신 반대편 건물 자리 쪽 길이 열린다.
- **AI**
  - 체력 30% 이하인 쓰러지는 건물의 낙하 구역에는 머무르지 않는다.
  - 보통 AI는 앞마당이 공격받을 때, 공격 경로를 막을 수 있는 쓰러지는 건물이 근처에 있으면 그 건물을 공격해 쓰러뜨린다(임시 규칙).
  - 길이 막히면 경로를 다시 계산한다.
- **화면:** 쓰러지는 애니메이션(1.5초, 회전 + 먼지 + 파편)과, 누운 건물 잔해 메쉬. 낙하 구역에 깔린 유닛 피격 연출. 붕괴 후 미니맵에 막힌 구역 표시.
- **테스트 추가:** 낙하 구역 차단, 원래 자리 개방, 유닛 피해·밀려남, 예고 단계, 연결성 조합 검사, 결정론.

## 3. 진지 건물 (Garrison, 스타크래프트 벙커 방식)
- 도시 건물 중 일부(2인 6~8채, 4인 12~16채, 대칭)를 진지 가능으로 표시한다. 앞마당 입구, 중앙 주변, 측면 길목에 둔다.
- **들어갈 수 있는 유닛:** 보병 분대만(레인저, 스카이가드, 민병대, 화염방사). 차량·공병·공중은 안 된다. 수용은 3분대(임시값).
- **규칙**
  - 빈 진지는 누구나 들어갈 수 있다. 다른 플레이어가 있는 진지에는 못 들어간다. 동맹은 같이 들어갈 수 있다.
  - 안의 분대는 피해를 받지 않는다. 건물이 대신 맞는다.
  - 안에서 사격하며 사거리 +2m(임시값).
  - 나가기 명령으로 즉시 나온다. 건물이 붕괴하면 강제로 튀어나온다(2번의 피해 규칙).
  - **카운터:** 화염방사 분대는 진지 건물에 피해 ×2. 다연장·폭격 ×1.5는 2번 규칙과 같다.
  - 휴전 중에는 자기 본진 밖 진지에 들어갈 수 없다(기존 휴전 규칙).
- **명령:** EnterGarrison(분대들, 건물), ExitGarrison(건물). 입력 지연·롤백과 맞게 Quantum 명령으로 만든다.
- **화면**
  - 진지 건물 위에 들어간 분대 수 아이콘, 소유자 팀 색 띠
  - 창문에서 총구 화염
  - 진지 건물은 문 표시나 모래주머니로 들어갈 수 있다는 걸 알 수 있게 한다
- **조작:** 보병을 선택한 채 진지 건물을 누르면 들어간다. 진지 건물을 선택하면 "모두 나가기" 버튼.

## 4. 닫힌 맵 (끝없는 들판 금지)
- 맵 경계는 파괴 불가 고층 건물 벽, 방벽, 바다 제방 중 하나로 **눈에 보이게 막는다**. 경계 밖에는 아무것도 없는 들판이 보이면 안 된다.
- 경계 밖은 어둡게 처리한 도시 실루엣(멀리 보이는 빌딩 윤곽) 또는 안개로 마감한다.
- 카메라
  - 화면 가장자리가 경계를 크게 벗어나지 않게 이동 범위를 제한한다(최대 줌 아웃에서도 경계 밖이 화면의 10%를 넘지 않게).
  - 최대 줌 아웃 높이도 이에 맞춰 낮춘다.
  - 미니맵에 경계를 표시한다.

## 5. AI
- 보통
  - 앞마당 입구와 중앙의 진지 건물에 보병을 넣어 방어한다.
  - 적 진지는 화염방사·다연장으로 깨게 한다.
  - 측면 웨이브 일부는 지름길 건물을 부숴 길을 연다(확률 25%, 임시값).
- 쉬움: 진지에 들어가지만 건물을 일부러 부수지는 않는다.
- 길이 막힌 경로를 반복 시도하는 끼임이 생기지 않게, 붕괴 이벤트 때 경로를 다시 계산한다.

## 6. 성능 (모바일)
- 도시 건물은 종류별 절차 메쉬를 한 번 만들어 재사용하고(인스턴싱 또는 공유 메쉬), 손상 단계마다 메쉬나 머티리얼만 바꾼다.
- 멀리 있는 건물은 저면수 버전(LOD 2단계)을 쓴다.
- 붕괴 연출(무너짐 + 먼지 + 잔해 메쉬 교체)은 low에서 단순화한다.
- 품질별 그리기 호출·삼각형을 항목 17 대비 표로 기록한다. low는 2배를 넘지 않게 한다.
