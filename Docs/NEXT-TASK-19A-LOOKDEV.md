# 항목 19A — 그래픽 룩 개발 (먼저 탐색하고 비교한 뒤 설정 변경)

시작 조건: 항목 20과 항목 21(도시 전장, NEXT-TASK-21-CITY.md)을 끝내고 push한 뒤 시작한다. **전장은 도시다.** 바닥·숲·맵 밖·지형 높낮이 축은 NEXT-TASK-21-CITY.md 8번의 도시 기준으로 탐색한다.
이 파일은 NEXT-TASK-19.md보다 **먼저** 한다. 19.md의 수치(FOV 30, 채도 +12 등)는 **출발점일 뿐 확정값이 아니다.** 이 파일의 탐색 결과로 값을 정한 뒤 19.md의 작업 목록을 적용한다.
CLAUDE.md 규칙, visual-style 스킬, 결정론 유지. 시뮬레이션은 건드리지 않는다(19.md 5-b 건물 간격만 예외). 단계마다 커밋·push.

## 왜 이렇게 하나
지금 화면은 기능은 다 있지만 컨셉 아트보다 밋밋하다.
- 낮은 흙벽 같은 능선, 끝없는 초원, 작은 유닛, 빗금, 단색 바닥
- 값을 하나씩 감으로 바꾸면 되돌리기 어렵다. 그래서 여러 안을 같은 장면에서 나란히 찍어 비교하고, 기준표로 고른 뒤에 설정을 바꾼다.


## 목표 방향 변경 (11/8 사용자 지정): "Art of War 3 같은 느낌"
사용자가 모바일 RTS **Art of War 3: Global Conflict**(Gear Games) 플레이 영상을 보여 주며 이 느낌을 원했다. 08_target_style(스타일라이즈드 로우폴리)보다 **이 방향이 우선**이다.
- 참고 화면: `concept-art/aow3-ref/` (사용자가 영상에서 캡처해 넣는 이미지. 폴더가 비어 있으면 아래 특징 설명만으로 진행하고, 보고서에 "참고 캡처 없음"이라고 적는다)
- **베끼지 말 것:** 그 게임의 모델·텍스처·UI·로고·맵 배치·유닛 디자인을 복제하지 않는다. 분위기와 표현 방식만 참고한다. 유닛·건물은 지금의 가상 진영 디자인과 VISUAL-REFERENCE.md 규칙(실존 무기와 닮지 않게)을 유지한다.

### 이 방향의 특징 (탐색 기준으로 삼는다)
1. **반실사 현대전.** 장난감 같은 과장 비율 대신 실제에 가까운 비율, 금속·도장·콘크리트 질감, 모서리 마모와 먼지·그을음.
2. **절제된 군용 색.** 회색, 카키, 국방색, 콘크리트, 녹슨 갈색. 채도는 낮다. 팀 색은 차량 띠, 깃발, 선택 링 같은 작은 표식에만 쓴다. 발광은 기능 표시에만 쓰고 약하게.
3. **높은 원근 카메라.** 55~65° 정도로 내려다본다. 기본 줌에서는 꽤 넓게 보여 전선이 한눈에 들어오고, 줌 인하면 디테일이 보인다. 유닛은 작아도 실루엣과 그림자로 구분된다.
4. **자연광.** 부드러운 그림자와 약한 AO. 블룸은 폭발·화염 순간에만 쓰고, 외곽선은 쓰지 않거나 아주 약하게.
5. **파괴된 도시와 전장 흔적.** 무너진 건물, 잔해, 금 간 도로와 차선, 포탄 구덩이, 불탄 차량, 계속 타는 불과 연기 기둥. 항목 21(도시 전장)과 맞는다.
6. **이펙트 비중이 크다.** 폭발 화염 + 검은 연기 기둥, 튀는 파편, 예광탄, 미사일 연기 꼬리, 붕괴 먼지 구름, 피격 불꽃, 화면을 채우는 교전 밀도.
7. **기지는 콘크리트 부지 위.** 건물은 바닥 패드 위에 서고, 기지 주변에 방벽·모래주머니·조명탑 같은 군사 시설 소품이 있다.
8. **간결한 HUD.** 화면 가장자리에 작게 둔다. 전장을 가리지 않는다.

### 절차 생성 파이프라인에서 이 느낌을 내는 방법 (탐색 축에 추가)
지금은 팔레트 텍스처 한 장에 평면 색이다. 아래를 코드로 만들고 축마다 비교한다.
- **질감 텍스처 생성:** 금속 패널, 도장 마모, 콘크리트, 아스팔트, 녹, 먼지를 코드로 굽는다. 아틀라스 1~2장, 각 512~1024.
  - 트라이플래너 또는 UV 투영으로 디테일 노이즈와 오염(grime)을 입힌다.
  - 노멀맵으로 패널 이음새와 리벳을 표현한다.
  - 거칠기·금속성 채널도 둔다.
- **모서리 베벨:** 메쉬 모서리를 깎아 빛을 받게 한다. 실사 느낌의 핵심이다. high는 2단, low는 없음.
- **데칼:** 도로 차선, 균열, 기름 얼룩, 그을음, 포탄 구덩이, 건물 외벽 금. 최대 개수를 정한다.
- **재질 단계:** 같은 건물이라도 손상 단계에 따라 그을음·균열 데칼과 질감이 늘어나게.
- **이펙트 고도화:** 폭발마다 화염 → 연기 기둥(수 초 지속) → 잔불. 파티클 수와 지속 시간은 품질별로 다르게.
- **유닛 디테일 LOD:** high에서 바퀴·궤도·안테나·해치 같은 작은 부품을 더한다. 줌 아웃 시 단순화.

### 후보 구성 변경 (4번 "후보 조합과 결정"을 이렇게 바꾼다)
- **후보 A "반실사 밀리터리(Art of War 3 방향)": 기본 목표.**
- 후보 B "스타일라이즈드(08 방향)": 비교용
- 후보 C "성능 우선": A를 low 사양 폰 기준으로 줄인 것
- 목표 분위기 유사도는 `aow3-ref` 캡처(없으면 위 특징 8개)를 1순위 기준으로 본다.
- A가 성능 기준(low 현재 수준, medium +30% 이내)을 못 맞추면, 무엇을 덜어서 맞췄는지 기록하고 A를 유지한다. 맞출 수 없는 항목만 사용자 결정 사항으로 남긴다.
- 19.md의 외곽선·채도 상향·블룸 강화 같은 스타일라이즈드 쪽 값은 A에서 쓰지 않거나 약하게 한다.

## 1. 비교 환경 만들기
- **고정 장면**: 2인 맵에서 같은 시드로 AI 대전을 돌려 특정 프레임(3:00 채집, 7:30 첫 교전, 11:00 대규모 교전)을 저장하고, 매번 같은 상태로 불러와 찍는다. 화면 결과가 시드·프레임만으로 재현돼야 한다.
- **고정 시점 5개**
  - A. 본진 근접
  - B. 다리와 강 협곡
  - C. 중앙 교전
  - D. 맵 전체
  - E. HUD 포함 실제 게임 화면
- **해상도 2종**: 1920×1080, 폰 비율 2400×1080을 렌더 스케일 0.75로. 품질 low·medium·high 각각.
- **참고 보드**: `concept-art/2026-11-07/` 00~09번, 특히 08_target_style.png(목표 분위기)와 03·04·05(건물 형태).
- **비교 시트 생성기**: 여러 안을 한 장에 격자로 붙이고 각 칸에 안 이름과 수치(그리기 호출, 삼각형, 예상 GPU 비용)를 적어 `screenshots/lookdev/<축>_<시점>.png`로 저장하는 에디터 도구를 만든다.
- **설정은 데이터로**: 카메라·조명·후처리·지형 높이·팔레트·외곽선·유닛 크기를 `VisualProfile` 에셋 하나에 모으고, 코드 상수에서 읽던 값을 이 에셋에서 읽게 바꾼다. 안마다 프로필 에셋을 하나씩 두고 바꿔 끼워 비교한다. 나중에 사용자가 다른 안을 고르면 에셋만 바꾸면 되게 한다.

## 2. 평가 기준 (안마다 1~5점, 보고서 표로)
1. **가독성**: 유닛·건물이 바닥과 또렷이 구분되는가. 팀 색이 한눈에 보이는가. 전차 한 대가 폰 화면에서 손가락으로 누를 만한 크기인가(1080p 기준 전차 가로 40px 이상 목표).
2. **입체감**: 대지·절벽·강 협곡의 높낮이가 읽히는가. 고지대·비탈길이 구분되는가.
3. **목표 분위기 유사도**: 08_target_style과 나란히 놓았을 때 색감·빛·구도가 가까운가.
4. **정보 전달**: 자원(철 결정, 숲), 건설 가능 지역, 점령지, 길(중앙·측면·뒷길)이 바로 보이는가.
5. **눈의 피로**: 블룸 번짐, 과한 채도, 지나친 그림자 대비가 없는가.
6. **성능**: 품질별 그리기 호출·삼각형·후처리 비용. low는 현재 수준을 넘지 않을 것, medium은 +30% 이내.

## 3. 탐색할 축 (축마다 3~5안, 다른 축은 기본값 고정)
1. **카메라**: FOV 25/30/35/45 × 피치 45/50/55, 기본 높이는 "전차 40px" 기준으로 역산. 줌 최소·최대에서 본진 전체와 교전 장면이 한 화면에 드는지.
2. **유닛·건물 표시 크기**: 유닛 1.0/1.2/1.4배, 건물 본체 비율 75/80/85%. 선택 반경과 함께.
3. **조명 프리셋**: 따뜻한 오후(#FFF4E0, 고도 40°) / 맑은 정오(흰빛, 고도 60°) / 늦은 오후(주황, 고도 25°, 긴 그림자). 환경광의 하늘·적도·땅 색 조합 포함.
4. **후처리**: 톤매핑 Neutral vs ACES, 블룸 세기·문턱값 3단계, SSAO 반경·세기 3단계(high·medium만), 채도·대비 0/+10/+20, 약한 비네트 유무.
5. **외곽선 방식**: 없음+림라이트 / 뒷면 확장 메쉬(inverted hull) / 깊이·노멀 경계 검출 렌더러 기능. 각각 모양과 비용.
6. **지형 높낮이**: 대지 높이 3/5/8m, 절벽 층 수 2/3/4, 절벽 가장자리 들쭉날쭉 정도 3단계, 강바닥 깊이 2/4/6m. 고지대·비탈길이 잘 보이는 조합.
7. **바닥 팔레트**: 3종(밝은 연두 / 올리브·흙 / 채도 높은 초록) × 얼룩 크기 2종 × 도로 색 2종. 구역 색(본진 콘크리트, 강가 모래, 중앙 그을린 흙)이 서로 구분되는지.
8. **숲·바위**: 나무 밀도 3단계, 침엽·활엽 비율, 잎 색 3종 조합, 군락 가장자리 덤불 유무.
9. **맵 밖 처리**: 어두운 단색 / 안개 / 절벽 아래 바다(물) 3안.
10. **건설 금지 빗금**: 건설 모드에서만 표시하는 방식 3안(빗금 / 붉은 반투명 / 격자 칸 색). 건설 가능한 칸은 초록 격자.

## 4. 후보 조합과 결정
- 축별 1~2위를 골라 **완성 후보 3개**(예: 선명형 / 따뜻한 일러스트형 / 성능 우선형)를 만들고, 시점 5개 × 품질 3단계로 다시 찍는다.
- 각 후보를 08_target_style과 현재 화면(before)과 나란히 놓은 비교 시트 `screenshots/lookdev/final_compare.png`를 만든다.
- 기준표 점수가 가장 높은 후보를 기본값으로 정한다. 동점이면 가독성 → 성능 순으로 고른다. 2·3위 후보도 프로필 에셋으로 남겨 둔다.
- 결정 근거를 `LOOKDEV.md`에 적는다. 축별 비교 시트 경로, 점수표, 고른 값, 버린 안과 이유, 품질별 비용을 넣는다.
