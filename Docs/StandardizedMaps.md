# 다섯 맵의 공통 규격과 외곽 경계

| 맵 | 지형과 이동 | 전체 화면 |
| --- | --- | --- |
| `Map4P` | 침엽수와 산악 능선으로 경계를 이었다. 참고 맵처럼 중앙 섬을 12각 강(안쪽 반지름 43m, 폭 14m)이 두르고 X자 간선도로가 대각선 다리 4개로 건넌다. 통과 불가 대지는 NatureForge 숲 군락으로 보인다. | [표준](status_images/map_standard.png) |
| `MapDesert` | 적갈색 협곡, 사구와 사막 바위를 연결했다. 경계 바깥 수로를 걷었다. | [사막](status_images/map_desert.png) |
| `MapArchipelago` | 연안 암벽이 라군과 해로를 감싼다. 해로 폭(최대 22m 좁힘)과 중심선(±7m)을 굽이치게 해 사각 섬 대신 곶과 만이 생긴다. | [다도해](status_images/map_archipelago.png) |
| `MapStrait` | 양안의 연안도로와 교량을 내해 안에 묶었다. 양안 안쪽(|x|<62m)의 겹치던 공통 도로를 걷어 해안 간선도로·교량 접근로 하나로 읽힌다. | [해협](status_images/map_strait.png) |
| `MapUrban` | 외곽 벽 건물 열을 능선으로 바꾸고 기존 도시와 도로망을 연결했다. | [시가지](status_images/map_urban.png) |

다섯 맵의 Quantum XZ 경계는 각각 ±160m다. 자리별 70m × 70m 본진 평지와 세 곳의 교량 접근로를 정의했다. 후방 안전 자원, 전진 확장 자원과 분쟁 지역 자원을 세 단계로 배치했으며, 후방의 6m 동선은 건설 가능 구역에서 제외했다. 추출 시설의 노드 맞춤 반경은 이 맵들에서 10m다. 큰 숲에서는 공병의 건설 및 진입 위치가 자원 노드 외곽을 사용한다.

하나의 경계 데이터를 지상·수상 NavMesh와 Quantum 이동 제한, RTS 카메라에 적용한다. 기존 육상 맵의 외곽 수로와 수문은 제거했다. 본진 운하에서는 계속 선박을 건조하고 운항할 수 있으며 여러 본진을 돌던 외곽 항로는 사라졌다. 다도해와 해협에서는 내해 연결을 유지했다.

Unity에서 **Tools → Factory Wars → Bake Standardized Maps**를 실행하면 다섯 맵의 데이터, 씬, 지상·수상 NavMesh를 다시 생성한다. 디버그용 `QuantumGameScene`의 규격은 기존과 같다.

## 참고 맵 반영 (2026-11-21, Claude)

- 중앙 강은 원 대신 12각형이다. 변 가운데가 다리라서 다리 앞뒤 13m가 곧고(다리 직선 규칙), 꼭짓점 꺾임은 30도다. 다리 옆 물길 조각은 상판 폭에 맞춰 잘라 막는다. 통째로 빼면 다리 옆 물을 걸어서 건너는 틈이 생긴다.
- 운하 위에 있던 철광 `(-82,-118)`을 `(-71,-111)`로, 운하에 붙은 `(-148,-76)`을 `(-150,-73)`으로 옮겼다(표준·사막·시가지·다도해·해협 공통).
- 강 규칙 검사 가운데 사행·폭 3~5m·회전 순서는 기지 운하 규칙이므로 중앙 강(반지름 70m 안)을 제외한다. 직선·폭 일정·빈틈없는 차단·자원/다리 회피는 중앙 강에도 적용한다.
