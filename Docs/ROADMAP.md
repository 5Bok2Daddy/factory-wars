## 챕터 3 — 규칙 마무리 + AI와 플레이 가능한 첫 판

**완료 기준:** Unity 에디터에서 진영·맵을 고르고 AI 상대로 처음부터 승패까지 한 판을 할 수 있다. Android APK가 빌드된다.

3-0. **자원·지형 개편** (DESIGN-RESOURCE-TERRAIN.md 기준, 커밋마다 전체 테스트 통과)
- a. 비용 구조: ResourceCost, 자금을 철로 기계적 치환, 외교·쪽지 철, 시작 자원을 MapSpec으로
- b. 데이터: 설계 4·5장 비용·해금, 정제소→가공소 이름 변경, 집하장, 시작 공병 4 (테스트 씬은 현행 유지)
- c. 채집: 철·목재, 사령부·집하장 반입, 작업 지점, 고갈 노드 유지
- d. 전기: 축적·한도·유지비·정전·이벤트, 기존 전력 용량 방식 제거
- e. 가공소: 변환, 켜기·끄기, 강철
- f. 거부 사유: 부족 자원 비트 마스크, 인구 한도, 수리비 자원별
- g. 지형: MapSpec 지형 목록, 씬 생성, 건설 검사(3 이격, 건설 금지 구역), NavMesh 재굽기
- h. 맵: 2인·4인 재배치, 대칭·연결·협곡 폭 테스트, 횡단 재측정, 맵 이미지 첨부
- i. AI: 공병 배분, 새 빌드오더, 전기·강철 관리, 집하장 확장
- j. 휴전·울타리: 초반 휴전(기본 7분, 0·5·7·10분 선택), 본진 입구 다리의 `Barrier` NavMesh 영역을 휴전이 끝나면 개방, 휴전 중 공격 금지(공중·포격 포함)·외교 허용, 다리 위와 양쪽 끝 건설 금지, 상단 카운트다운, BridgesOpened

3-1. **규칙 마무리**
- 완료. 해금 트리는 3-0b에서 설계 4장으로 교체
- 건물은 NavMesh에 넣지 않고 밀어내기 + 모서리 우회로 처리. 협곡·입구는 건설 금지 구역으로 보호
- 승리 조건, 스카이가드·호크 해석은 현재 구현 유지

3-2. **모바일 가로 화면 조작**
- 카메라: 한 손가락 드래그 이동, 핀치 줌, 맵 경계 제한
- 선택: 탭 선택, 드래그 박스 선택, 같은 종류 더블탭 전체 선택, 부대 지정 버튼 3개
- 명령: 땅 탭 이동, 길게 누르기 공격 이동, 적 탭 공격, 정지 버튼
- HUD: 상단 철·목재·강철·전기 저장/한도(순증감)·인구, 좌하단 미니맵(탭하면 카메라 이동, 지형 색), 우하단 건설·생산 패널(해금 표시, 자원별 비용, 대기열), 건물 선택 시 생산 프리셋 편집, 가공소 켜기·끄기
- 정전 표시: 전기 칸 경고, 멈춘 건물 위 아이콘
- 외교·쪽지 패널: 플레이어 목록, 동맹 제안·수락·거절·파기 버튼(철 비용 표시), 정해진 문구 쪽지, 받은 쪽지 3초 표시 + 쪽지함, 철·목재·강철·전기 부족, 인구 한도, 건설 불가 지형 등 거부 사유 표시
- 화면 비율 16:9~21:9 대응, 버튼 최소 크기 약 9mm

3-3. **AI 상대 (쉬움·보통)**
- 결정론 유지: 시뮬레이션 안에서 동작 (Quantum 봇 SDK 또는 규칙 기반 시스템)
- 완료(구 규칙). 경제 판단은 3-0i에서 교체: 공병 철 6:목재 4 → 발전소 이후 7:3, 발전소 → 가공소 → 무기 생산, 전기·강철 관리, 집하장 확장
- 난이도 차이: 판단 주기, 공격 시작 시점, 유닛 조합 다양성
- 자유 대전에서 AI의 외교: 쉬움은 제안을 받으면 무작위, 보통은 가장 강한 상대를 견제하는 쪽과 동맹 (비용 규칙 동일 적용)
- AI 외교 개편: 전원 동맹 금지(공동 승리는 사람끼리 외교로만), 플레이어 쌍별 관계 점수(-100~100), 수락 조건(점수 기준, 제안자가 최강이 아님, 공동의 적 유지), 쪽지로 점수를 쌓은 뒤 제안, 파기 조건

3-4. **화면 흐름**
- 시작 화면 → 진영 선택 → 맵 선택(2인/4인), 봇 수·난이도, 모드(1대1·자유 대전·팀전) → 대전 → 결과 화면(승패, 경기 시간, 생산·손실 수) → 시작 화면
- 일시정지 메뉴(AI 대전만), 설정(음량 자리만, 언어는 한국어 기본)
- 색 선택: 팔레트 8색(색각 이상도 구분), 한 판 안 중복 금지, AI는 남은 색 자동. RuntimePlayer로 전달. 진영 구분은 색이 아니라 형태(자유 연방 돔·매끈한 패널, 대륙 연방 각진 요새). 남색·진홍은 기본 추천색

3-7. **Android 개발 빌드**
- 먼저 `PlaybackEngines\AndroidPlayer`의 SDK·NDK·OpenJDK 실제 설치를 확인한다. 비어 있으면 빌드는 건너뛰고 보고서에 "Hub에서 SDK & NDK Tools 제거 후 재설치"를 적는다.
- 정상이면 Development Build APK를 `FactoryWars\Builds\`에 만든다 (IL2CPP, ARM64, 가로 고정). 빌드 폴더는 Git 제외.

3-5. **절차적 로우폴리 그래픽** (완료. 구현은 사용자 승인 후. 규칙은 visual-style 스킬, 설계는 보고서 "3-5 그래픽 설계")

- Quantum 온라인 세션 시작, 플레이어 슬롯 ↔ PlayerRef 매핑
- 연결 끊김: 봇이 대신 조종(Player Replacement), 재접속 시 복귀, 상대 응답 지연 시 "연결 대기" 표시, 60초 넘으면 기권 처리

- 네트워크 상태 표시(핑), 입력 지연 체감 기록
- 로그인: 익명(기기 ID). 닉네임은 자동 생성 이름(예: 지휘관 4821) — 자유 닉네임 금지 (애플 UGC 규정)

- 사용 App ID는 개발용 그대로. **무료 100 CCU 활성화는 하지 않는다** (사용자가 출시 직전 운영용 앱에서 직접)
