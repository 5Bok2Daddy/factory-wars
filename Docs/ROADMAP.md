## 챕터 3 — 규칙 마무리 + AI와 플레이 가능한 첫 판

**완료 기준:** Unity 에디터에서 진영·맵을 고르고 AI 상대로 처음부터 승패까지 한 판을 할 수 있다. Android APK가 빌드된다.

3-1. **규칙 마무리**
- 건물 해금 (GDD 건물표): 사령부 → 발전소·보급창 / 발전소 → 정제소·병영 / 병영 → 연구소·군수공장·방어탑 / 군수공장 → 비행장 / 군수공장 + 연구소 → 중공업 기지
- 유닛이 건물을 통과하지 않게 (건설된 건물을 길찾기 장애물로 반영)
- 승리 조건 통일: 모든 모드에서 사령부와 생산 건물(병영·군수공장·비행장·중공업 기지)을 모두 잃으면 패배
- 확정된 해석: 스카이가드(공중 우선, 공중이 없으면 지상을 약하게), 호크(지상 대장갑 피해 절반) — 현재 구현 유지

3-2. **모바일 가로 화면 조작**
- 카메라: 한 손가락 드래그 이동, 핀치 줌, 맵 경계 제한
- 선택: 탭 선택, 드래그 박스 선택, 같은 종류 더블탭 전체 선택, 부대 지정 버튼 3개
- 명령: 땅 탭 이동, 길게 누르기 공격 이동, 적 탭 공격, 정지 버튼
- HUD: 상단 자금·전력·인구, 좌하단 미니맵(탭하면 카메라 이동), 우하단 건설·생산 패널(해금 표시, 비용, 대기열), 건물 선택 시 생산 프리셋 편집
- 외교·쪽지 패널: 플레이어 목록, 동맹 제안·수락·거절·파기 버튼(비용 표시), 정해진 문구 쪽지, 받은 쪽지 3초 표시 + 쪽지함, "자금 부족" 등 거부 사유 표시
- 화면 비율 16:9~21:9 대응, 버튼 최소 크기 약 9mm

3-3. **AI 상대 (쉬움·보통)**
- 결정론 유지: 시뮬레이션 안에서 동작 (Quantum 봇 SDK 또는 규칙 기반 시스템)
- 행동: 공병 채집 → 건설 순서 → 생산 → 일정 규모가 되면 공격 웨이브 → 확장 노드 점유
- 난이도 차이: 판단 주기, 공격 시작 시점, 유닛 조합 다양성
- 자유 대전에서 AI의 외교: 쉬움은 제안을 받으면 무작위, 보통은 가장 강한 상대를 견제하는 쪽과 동맹 (비용 규칙 동일 적용)

3-4. **화면 흐름**
- 시작 화면 → 진영 선택 → 맵 선택(2인/4인), 봇 수·난이도, 모드(1대1·자유 대전·팀전) → 대전 → 결과 화면(승패, 경기 시간, 생산·손실 수) → 시작 화면
- 일시정지 메뉴(AI 대전만), 설정(음량 자리만, 언어는 한국어 기본)

3-5. **임시 그래픽**
- 진영 색 도형(자유 연방 남색 #1F3A6B, 대륙 연방 진홍 #A3222B, 3·4번 플레이어 색 별도), 크기별 형태 구분, 체력바, 선택 링, 공격선·피격·파괴 효과(간단한 파티클), 건설 진행 표시

3-6. **AI 대 AI 자동 대전**
- 화면 없이 20판(2인 맵 10, 4인 맵 10) 돌려 진영별 승률, 평균 경기 시간, 시간대별 자금 수입을 기록
- 목표: 경기 시간 10~15분, 진영 승률 40~60%. 벗어나면 원인 추정만 보고서에 적고, 수치 조정은 챕터 5에서

3-7. **Android 개발 빌드**
- 먼저 `PlaybackEngines\AndroidPlayer`의 SDK·NDK·OpenJDK 실제 설치를 확인한다. 비어 있으면 빌드는 건너뛰고 보고서에 "Hub에서 SDK & NDK Tools 제거 후 재설치"를 적는다.
- 정상이면 Development Build APK를 `FactoryWars\Builds\`에 만든다 (IL2CPP, ARM64, 가로 고정). 빌드 폴더는 Git 제외.

## 챕터 4 — 온라인 방 코드 대전 (2~4인)

**완료 기준:** 에디터 2~4개(Unity Multiplayer Play Mode)로 방을 만들고 참가해 끝까지 대전할 수 있다. 같은 빌드의 Android 기기와 에디터가 함께 대전된다.

- Photon Realtime 방: 6자리 방 코드 생성·참가, 대기실(진영 선택, 준비, 빈자리 봇·난이도, 모드, 공동 승리 on/off), 방장 시작
- 방 입장 시 게임·데이터 버전 일치 확인, 불일치면 안내
- Quantum 온라인 세션 시작, 플레이어 슬롯 ↔ PlayerRef 매핑
- 연결 끊김: 봇이 대신 조종(Player Replacement), 재접속 시 복귀, 상대 응답 지연 시 "연결 대기" 표시, 60초 넘으면 기권 처리
- 개발 빌드에서 체크섬 디싱크 감지 켜기, 디싱크 시 프레임 덤프 저장
- 네트워크 상태 표시(핑), 입력 지연 체감 기록
- 로그인: 익명(기기 ID). 닉네임은 자동 생성 이름(예: 지휘관 4821) — 자유 닉네임 금지 (애플 UGC 규정)
- 쪽지는 정해진 문구만, 자유 채팅 없음
- 사용 App ID는 개발용 그대로. **무료 100 CCU 활성화는 하지 않는다** (사용자가 출시 직전 운영용 앱에서 직접)

## 챕터 5 — 밸런스와 남은 콘텐츠

**완료 기준:** 모듈 8종 + 진영 전용 2종이 동작하고, AI 대 AI 100판에서 목표 범위(경기 10~15분, 승률 45~55%)에 들어온다.

- 연구소의 모듈 개발(비용·시간) → 생산 프리셋에 장착 가능
- 남은 모듈: 소이탄, 연막 발생기(체력 30% 이하), 터보 엔진, 긴급 후퇴(체력 20% 이하), 수리 키트(비전투 시), 정찰 레이더
- 진영 전용 모듈: 자유 연방 "위성 연계"(시야 +30%, 은폐 탐지), 대륙 연방 "인해 보급"(파괴 시 생산비 25% 환급)
- AI가 모듈과 프리셋을 쓰도록 확장
- AI 대 AI 100판 → 임시값 조정 (데이터 에셋만), 변경 전후 표를 보고서에
- 튜토리얼 (조작·채집·건설·생산·외교 순서의 짧은 안내)
