# 설계 변경: 자원 체계 v2 + 지형지물

작성: 2026-11-06. 사용자 확정 사항과 임시 수치. 이 파일이 GDD의 "자원·건물 체계"와 TASK-01·02의 자금·전력 규칙을 **대체**한다.
수치는 전부 임시값이다. 데이터 에셋에만 두고, 챕터 3-6·5의 AI 대 AI 결과로 조정한다.

## 1. 사용자 확정 사항

1. 자원은 **철 · 목재 · 전기 · 강철 · 인구** 5종. 자금은 없앤다.
2. 초반은 철과 목재. 공병이 맵의 **철광산**과 **숲**에서 채집한다.
3. **전기는 쌓이는 자원 + 가동 유지비.** 발전소가 초당 전기를 만들어 저장 한도까지 쌓는다. 상위 유닛·건물을 만들 때 쓰고, 상위 건물은 가동 중에 전기를 계속 소모한다. 전기가 0이면 상위 건물이 멈춘다.
4. **강철이 5번째 자원.** 가공소가 철 + 전기로 강철을 만든다. 중형·대형 유닛과 상위 건물, 모듈에 필요하다.
5. **숲은 바뀌지 않는다.** 처음부터 끝까지 통과 불가 지형이고, 채집하면 매장량만 줄어든다. 길찾기를 실시간으로 갱신할 일이 없다.
6. 맵에 지형지물(바위, 언덕, 협곡)을 넣어 이동 불가 장애물과 길목을 만든다.

## 2. 빌드업 흐름

| 단계 | 시간(목표) | 하는 일 | 쓰는 자원 |
| --- | --- | --- | --- |
| 초반 | 0~3분 | 공병 늘리기, 철·목재 채집, 보급창·병영, 소형 유닛 | 철, 목재 |
| 전력 확보 | 3~5분 | 발전소 → 전기 축적 시작, 가공소로 강철 생산 | 철, 목재 → 전기, 강철 |
| 전쟁 준비 | 5~9분 | 군수공장·연구소·비행장·중공업 기지, 중형·대형 유닛, 모듈 | 강철, 전기 (+유지비) |
| 교전 | 7분~ | 확장 지점 점유, 공격 | 전부 |

## 3. 자원 규칙

| 자원 | 얻는 법 | 반입·저장 | 시작값 |
| --- | --- | --- | --- |
| 철 | 공병이 철광산에서 1회 50, 채집 2초 | 사령부 또는 집하장에 반입. 한도 없음 | 500 |
| 목재 | 공병이 숲에서 1회 50, 채집 3초 | 사령부 또는 집하장에 반입. 한도 없음 | 300 |
| 전기 | 발전소 1개당 초당 +5 | 저장 한도 = 사령부 200 + 발전소 1개당 300. 한도에서 멈춤 | 0 |
| 강철 | 가공소: 철 2 + 전기 1 → 강철 1, 1초마다 | 한도 없음 | 0 |
| 인구 | 사령부 +10, 보급창 1개당 +20 | 한도 = 합계 (대륙 연방 +20%) | 0 / 10 |

- 기존 "전력 용량(생산/소비) 방식"과 "전력 부족 시 생산 속도 ×0.5"는 없앤다.
- 전기는 FP로 누적한다 (틱마다 `5 × DeltaTime`). 결정론 규칙 그대로.
- **가동 유지비 (초당 전기):** 연구소 1 (개발 중일 때), 군수공장 1 (생산 중일 때), 비행장 2 (생산 중일 때), 중공업 기지 3 (생산 중일 때), 방어탑 0.5 (상시). 가공소는 변환에 쓰는 전기 1/초가 유지비를 대신한다.
- **전기 0 (정전):** 연구소·군수공장·비행장·중공업 기지의 진행 타이머가 멈춘다(대기열·진행도 유지). 가공소 변환이 멈춘다. 방어탑 공격 간격 ×2. 병영·보급창·집하장·사령부는 영향 없음.
  - 전기가 다시 생기면 자동 재개. 여러 건물이 동시에 요구하면 같은 틱 안에서는 엔티티 순서대로 처리하되, 순서가 결정론적이어야 한다.
- 가공소에는 켜기/끄기(커맨드)가 있다. 끄면 철·전기를 쓰지 않는다. 기본값 켜짐.
- 비용 차감은 생산·건설 시작 시점에 전부(기존 방식 유지). 취소 환불 규칙도 기존과 같게 자원별로.
- 수리비: 기존 공식(회복 비율 × 건물 비용 × 0.5)을 자원별로 적용. 전기 비용도 포함.

### 비용 표기와 거부 사유

- 비용은 `ResourceCost { 철, 목재, 강철, 전기 }` 같은 구조체 하나로 모든 에셋(유닛·건물·모듈·외교)에 쓴다.
- `ActionRejected` 사유를 세분화: 철 부족 / 목재 부족 / 강철 부족 / 전기 부족 / 인구 한도 / 해금 안 됨 / 건설 불가 지형 / 쿨다운 / 모드 불가. 여러 개가 모자라면 첫 번째가 아니라 **모자란 자원 전부**를 비트 플래그로 담는다.
- 이벤트 추가: `PowerOutage(플레이어, 시작/끝)`, `BuildingPaused(건물, 사유)`.

## 4. 건물 (체력·건설 시간·부지 크기는 현재 구현값 유지)

| 건물 | 비용 | 해금 조건 | 역할 |
| --- | --- | --- | --- |
| 사령부 | 시작 건물 | — | 공병 생산, 철·목재 반입, 인구 +10, 전기 저장 200 |
| 집하장 (신규) | 목재 150 | 사령부 | 철·목재 반입 지점 (확장 기지용) |
| 보급창 | 철 100, 목재 200 | 사령부 | 인구 +20 |
| 병영 | 철 200, 목재 200 | 사령부 | 소형 유닛 |
| 발전소 | 철 150, 목재 150 | 사령부 | 전기 +5/초, 저장 +300 |
| 가공소 (정제소를 대체) | 철 250, 목재 150, 전기 100 | 발전소 | 철 2 + 전기 1 → 강철 1 /초 |
| 연구소 | 철 250, 목재 200, 전기 150 | 발전소 | 모듈 개발 |
| 군수공장 | 철 400, 목재 200, 전기 200 | 병영 + 발전소 | 중형 지상 유닛 |
| 방어탑 | 철 250, 목재 100, 전기 100 | 병영 + 발전소 | 방어 (상시 유지비 0.5) |
| 비행장 | 철 400, 강철 100, 전기 300 | 군수공장 + 가공소 | 공중 유닛 |
| 중공업 기지 | 철 500, 강철 200, 전기 400 | 군수공장 + 연구소 + 가공소 | 대형 유닛 |

- 기존 "정제소 = 반입 지점" 역할은 사령부·집하장으로 옮긴다. 정제소 에셋은 가공소로 바꾼다 (ID 변경 시 테스트·씬 참조 함께 수정).
- 해금은 "해당 건물이 **완성되어** 하나 이상 있을 때". 파괴되면 다시 잠긴다 (진행 중인 생산은 유지).
- 승리 조건(ROADMAP 3-1)은 그대로: 사령부 + 생산 건물(병영·군수공장·비행장·중공업 기지) 전부 잃으면 패배.

기존 자금 비용의 숫자를 그대로 두고 단위만 **철**로 바꾼다: 제안 철 300 (환급 150), 수락 철 150, 거절 무료, 파기 철 500, 쪽지 1명 철 50, 동맹 전체·모두 철 100. 5초 제한·30초 만료·60초 재동맹 금지 등 규칙은 그대로.

## 7. 지형지물

### 종류

| 종류 | 통과 | 건설 | 모양 | 비고 |
| --- | --- | --- | --- | --- |
| 철광산 | 불가 | 불가 | 원, 반지름 3 | 자원 노드. 고갈되면 바위로 남는다 (통과 불가 유지) |
| 숲 | 불가 | 불가 | 사각형·다각형 띠 (예: 20×6) | 자원 노드. 매장량만 줄고 모양은 그대로 |
| 바위 | 불가 | 불가 | 원·다각형, 반지름 2~5 | 산개 장애물 |
| 언덕 (절벽 고지) | 불가 | 불가 | 큰 다각형 | 1차는 통과 불가 덩어리. 고지대 사거리 보너스는 나중 (백로그) |
| 협곡 | 벽은 불가 | 벽은 불가 | 평행한 절벽 두 줄, 통로 폭 8~10, 길이 20~30 | 길목 |
| 강 | 불가 | 불가 | 짧은 회전 사각 조각의 띠, 폭 6~10 | 본진을 감싼다. 다리 2개로만 건넌다 |

- **공중 유닛은 지형을 무시한다.**
- 건물은 지형과 겹치면 안 되고, 철광산·숲 가장자리에서 3 이상 떨어져야 한다 (채집 동선이 막히지 않게). 위반 시 `ActionRejected(건설 불가 지형)`.
- **채집 지점:** 철광산은 원 둘레, 숲은 띠의 긴 변을 따라 여러 개의 작업 지점을 둔다. 공병은 비어 있는 가장 가까운 지점을 쓴다 (공병 혼잡 완화). 지점 수와 간격은 임시값.
- 지형은 **정적**이다. Unity NavMesh에 굽고 Quantum NavMesh로 가져온다. 런타임 갱신은 건물(3-1)만 해당.
- 지형 데이터는 `MapSpec`에 목록(종류, 모양, 위치, 매장량)으로 두고, 씬·NavMesh 굽기·건설 검사·미니맵이 같은 데이터를 쓴다.

### 강과 방어 울타리 (항목 18)

직선 해자와 도개교를 대체한다.

**강**

- 경로는 맵을 굽는 에디터(`RiverBuilder`)에서만 계산한다. 고정 시드 사인파 + 정수 해시 노이즈다. 실행 중에는 계산하지 않는다.
- 한 사분면만 만들고 회전으로 복제한다. 2인 맵은 점대칭, 4인 맵은 90도 대칭이다.
- 기준선은 본진 사각형의 경계다. 강가가 언제나 기준선 바깥이라 본진을 침범하지 않는다.
- 다리 중심 앞뒤 10m는 직선이고, 그 뒤로 곡률이 서서히 커진다. 코드 값은 12m다. 경계 조각이 폭을 평균내므로 2m를 더 잡았다.
- 폭은 6~10m이고, 지상 유닛이 건널 곳은 다리뿐이다. 다리 위치와 개수는 직선 해자 때와 같다.
- 본진 건설 가능 칸은 2인 맵 1864칸에서 1892칸, 4인 맵 2316칸에서 2358칸으로 늘었다.
- 차단은 `MapSpec.Terrain`의 `River` 조각이 맡고, `MapSpec.River`는 다리 밑까지 포함한 화면용 순서 목록이다.
- 그래픽은 물, 경사진 흙 강변, 땅 위 모래 띠를 잇는 리본 메쉬다. 장식 바위는 막힌 영역 안에만 둔다. 강은 바닥 메쉬의 끝에서 잘린다.

**방어 울타리**

- 다리는 언제나 내려와 있다. 휴전 중 막는 것은 NavMesh 영역 `Barrier`다. `TruceEndFrame`에 열리고 `BarrierOpened` 이벤트가 나간다.
- 울타리 메쉬는 화면 전용이다. 다리 양쪽 입구와 입구 좌우 강가 12m씩만 두르며 강 전체를 두르지 않는다. 안쪽 굽이는 물에 닿기 전까지만 간다.
- 금속 기둥과 가로 패널에 적색 경고등을 얹는다. 팀 색은 패널 테두리에만 쓴다.
- 연출: 휴전 중 느린 점멸, 종료 10초 전 빠른 점멸, 종료 시 상단 경고 "전쟁 시작 - 방어 울타리가 해제됩니다!", 1.7초 하강 후 비활성, 바닥 먼지(품질 낮음에서는 끈다).

### 2인 맵 (160 × 160, 좌표 0~160)

- 본진: (25, 25), (135, 135).
- **본진 구성 (양쪽 같게, 점대칭):** 사령부 뒤쪽(모서리 쪽)에 철광산 2개(각 4,000)와 숲 1개(6,000). 본진을 언덕·바위로 감싸고 **입구 2개(폭 12)**.
- **앞마당 확장 2곳:** 각 본진 입구 앞, 사령부에서 약 40. 철광산 1 (3,000) + 숲 1 (4,000).
- **숲 확장 2곳:** 비어 있는 두 모서리 (25, 135), (135, 25). 큰 숲 1 (8,000) + 철광산 1 (2,000). **협곡 하나로만 진입**.
- **중앙:** 큰 철광산 1 (6,000), 주위에 바위 4개.
- 본진 사이 경로 3개: 중앙(바위 사이), 좌·우 측면(협곡 통과). 직선 경로는 막는다.

### 4인 맵 (240 × 240)

- 본진: 네 모서리 (30, 30), (210, 30), (30, 210), (210, 210). **90도 회전 대칭.**
- 본진 구성: 2인 맵과 같음 (철광산 2 × 4,000, 숲 1 × 6,000, 입구 2개).
- **앞마당 확장 4곳:** 각 본진에서 중앙 방향으로 약 40. 철광산 1 (3,000) + 숲 1 (4,000).
- **변 확장 4곳:** 네 변 가운데 (120, 25), (25, 120), (215, 120), (120, 215). 철광산 1 (3,000) + 숲 1 (4,000). 이웃한 두 본진 사이 경로에 **협곡**을 둔다.
- **중앙:** 큰 철광산 1 (10,000) + 숲 2 (각 4,000). 언덕 고리로 둘러싸고 입구 4개.

### 검증

- 시작 위치·노드·지형이 대칭인지 (좌표 변환으로 테스트)
- 모든 본진 사이, 본진→모든 확장 지점이 지상 경로로 연결되는지 (NavMesh 경로 존재)

- 위에서 내려다본 맵 이미지(또는 ASCII)를 보고서에 첨부

## 8. 다른 챕터에 주는 영향 (설계 기준)

- **3-1 규칙 마무리:** 4장의 해금 트리, 정전 규칙, 집하장·가공소. 건물 길찾기 장애물은 지형과 같은 방식(또는 Quantum이 지원하는 동적 방식)으로 — 선택한 방법과 SDK 근거를 보고서에.
- **3-2 HUD:** 상단 바 `철 | 목재 | 강철 | 전기 저장/한도 (순증감 ±/초) | 인구 사용/한도`. 비용은 자원 아이콘으로, 모자란 항목은 빨간색. 알림: 철 부족·목재 부족·강철 부족·전기 부족·인구 한도·정전(멈춘 건물 위 아이콘)·건설 불가 지형. 가공소 켜기/끄기 버튼.
- **3-3 AI:** 공병 배분 초반 철 6 : 목재 4 → 발전소 이후 철 7 : 목재 3. 빌드오더 예: 공병 → 보급창 → 병영 → 발전소 → 가공소 → 군수공장 → (연구소) → 비행장/중공업 기지. 전기 순증감이 음수면 발전소 추가, 정전 직전이면 생산 대기. 강철 비축이 모자라면 가공소 추가. 확장 지점에 집하장.
- **3-5 임시 그래픽:** 철광산 = 회색 각진 바위 + 주황 광맥, 숲 = 짙은 녹색 원뿔 군집, 바위 = 회갈색 덩어리, 언덕 = 흙색 높은 블록, 협곡 벽 = 어두운 갈색 긴 블록. 노드 위 남은 매장량 표시, 고갈 철광산은 회색. 미니맵에 지형 색 반영.
- **3-6 AI 대 AI:** 기록 항목을 자원별 시간대 수입·전기 순증감·정전 시간으로 확장.
