- 차량: 차체 가감속 기울기, 포탑·포신 따로 회전(목표 추적), 사격 반동, 궤도 UV 흐름·바퀴 회전, 정지 시 서스펜션 흔들림, 파괴 시 불타는 잔해.

## 4. 보병 엄폐 (시뮬레이션 기능 — 결정론 규칙 엄수)
- **엄폐점(CoverSpot)**: 모래주머니 진지, 바리케이드, 도시 건물 잔해·벽, 컨테이너, 차량 잔해, 바위에 데이터로 붙인다. 각 점 = 위치·막는 방향·등급(낮음 25% / 높음 50% 피해 감소, 데이터)·점유 1명.
- **행동**: 보병(소형 보병만)이 적을 발견하고 교전에 들어가면, 반경 R(데이터) 안에서 적과 자신 사이를 막는 빈 엄폐점을 찾아 이동 → 웅크림/엄폐 자세로 사격. 명령 우선순위: 플레이어 이동 명령 > 엄폐. "위치 고수"면 엄폐 찾지 않음. 엄폐 대상 적이 다른 쪽으로 돌면 방향 다시 계산.
- **판정**: 공격자→목표 방향과 엄폐 방향의 각도(FP 내적)로 피해 감소 적용. 화염·포격·폭격(광역)은 엄폐 효과 절반(데이터). 엄폐물은 체력이 있어 부서진다(도시 붕괴·바리케이드와 연결).
- **표시**: 엄폐 중 보병 머리 위 작은 방패 아이콘, 엄폐점은 선택 시만 표시. 애니메이션: Cover Rifle Animset(없으면 웅크림+사격).
- **AI**: 엄폐 많은 길을 공격 경로 점수에 반영.
- 시뮬레이션 규칙: FP만, `frame.RNG`만, 엄폐 탐색은 틱당 상한(성능), 같은 엄폐점 경쟁은 엔티티 순서로 결정. 금지어 0건, 결정론 리플레이 시험.
- 시험: `Cover_InfantryMovesToCoverOnEngage`, `Cover_DirectionalReductionApplies`, `Cover_PlayerMoveOverridesCover`, `Cover_DestroyedCoverReleasesUnits`, `Cover_DeterministicAcrossRuns`.
