# 항목 36 — 시가전 배경 + 수로 (구입한 Synty 팩만 사용) (2026-11-14 20:30 작성)

참고 그림: `concept-art/2026-11-14/target_urban_ui.png` (사용자가 가져온 목표. 5장면: 기지·도로, 공중 작전, 시가 교차로, 엄폐 교전, 수로 해전). 이 그림의 **분위기와 구성**을 따르되 그림을 그대로 베끼지는 않는다.
권장 모델: Sonnet 5.5 이상(시각 판단이 많음). 33의 사용량 절약 규칙을 따른다(보고서는 맨 위 절만, 큰 로그 통째로 읽기 금지).

## 0. 사용자 결정·제약 (최우선)
- 숲·절벽·청록 바닥·주황 바위·청록 풀(Kenney/절차 지형)을 **시가지·도로·수로**로 바꾼다. **새 팩은 사지 않는다**(지금 가진 Synty Military·City·Battle Royale·Generic만).
- **구입 에셋 원본 수정 금지**(편집·재도색·크기 변경 금지). 모델·머티리얼은 있는 그대로 칸/배치 데이터에 연결만 한다. 배율·회전은 배치 데이터에서만. `Assets_PackFilesUnchanged` 시험을 통과시킨다.
- **시뮬레이션·NavMesh·지형 판정·건설 부지·수로 영역(`WaterNavMesh`, `WaterGate*`)은 바꾸지 않는다.** 이번 작업은 화면(View) 장식과 설정만. 장식이 길찾기·건설·시야를 막으면 안 된다.
- 숫자는 데이터(`VisualProfile`, 새 `UrbanDecorSpec`)에. 배치는 좌표 해시(UnityEngine.Random 금지). 인스턴스마다 새 머티리얼 금지.

## 1. 확인된 사용 가능 모델 (PC의 팩 폴더 검색 결과, 이름만 참고)

부족한 것은 보고서 표에 적고 사용자 구매 판단으로 남긴다.

## 2. 해야 할 일 (순서대로, 단계마다 캡처·시험·커밋)
### 36-A 바닥과 경계
- 청록 단색 바닥 → 아스팔트·콘크리트 톤(공용 머티리얼, 데이터 색). 본진·건설 부지는 콘크리트 패드(`Concrete_Base`)와 인도 연석.
- 맵 가장자리 절벽 슬래브 → **건물 외벽 열 + 방벽·울타리 + 잔해**로 닫힌 경계(건물 뒷면은 단순 블록 허용, 품질 낮음에서는 원경 건물 수 감소).
- 숲(나무 덩어리) 제거. 가로수(`Env_Tree`)는 도로변에 소수만.
### 36-B 도로망
- 이동 경로(세 갈래, 교차로, 보급 후보지)를 따라 도로 조각을 깐다. 중앙 교차로에 `Road_Cross`·횡단보도·신호등. 도로는 걸을 수 있는 영역 위에만, **NavMesh·콜라이더 없음**(장식).
- 차량 길과 보병 샛길의 폭 구분(공식은 `NEXT-TASK-35` 3-2의 값을 참고만 하고 지금 맵의 실제 폭을 따른다).
### 36-C 시가지 건물·엄폐 소품
- 중앙 교차로·자원지·보급 낙하 후보지 둘레에 건물 열을 빽빽하게(점유율 목표: 교차로 45~55%, 자원지 25~35%, 본진 10% 이하, 외곽 15~20%). 길·건설 부지·채집 통로는 비운다.
- 길가 10m마다 엄폐 소품(컨테이너·방벽·잔해 더미)을 두되 **게임 엄폐점 데이터와 맞춘다**: 소품이 엄폐 모양으로 보이는 곳에 실제 엄폐점이 있거나, 엄폐 없는 장식임을 구분(장식은 낮게/기울여서). 건물 위 올려보이는 소품은 금지.
- 쓰러지는 도시 건물(기존 CitySystem)은 지금 모델 그대로 두되 새 건물 모델 칸으로 연결할 수 있는지 확인하고, 안 되면 보고만 한다.
### 36-D 수로
- 지금 수로 영역의 윤곽을 따라 `WaterEdge`·`Port_Wall`로 양쪽 둑, 물 표면 머티리얼, 물가에 `Dock`·`Boat_Tie`, 건널목에 `Bridge`(시뮬레이션 다리·개방 상태와 일치할 때만). 수문 주변은 `Port_Wall`로 정리하고 수문 열림·닫힘 때 `FX_Waterfall_Foam` 재생.
- 물 위로 보병이 못 가는 것·배가 땅에 못 가는 것은 기존 시험(`WaterNavMesh` 계열)이 계속 통과해야 한다.
### 36-E 빛·색 (참고 그림은 밝고 깨끗함)
- 밝은 하늘색 환경광, 부드러운 그림자, 노출 과다(흰 바닥) 금지(밝기 245 이상 픽셀 3% 이하, 이전 항목 29 기준), 시야 가장자리 안개 약하게. `VisualProfile` 데이터로.
### 36-F 버그 수정
- 전략 미사일 경고 막대의 빨간 칠 부분이 글자를 가린다(`33_missile_warning.png`). 글자가 항상 위에 보이게(막대는 배경 레이어, 글자는 전경).

## 3. 성능
- 장식은 **정적 배칭·GPU 인스턴싱**(런타임 `StaticBatchingUtility`로 합치기는 허용, 원본 파일 수정 아님), 먼 건물 단순화, 품질별 장식 밀도 낮음 40%·보통 70%·높음 100%.
- 목표: 보통 품질 그리기 호출 350 이하·삼각형 55만 이하(맵 전체 시점 제외). 유닛 22칸 모델이 이미 호출을 많이 쓰므로, **장식은 별도 예산 150호출·20만 삼각형** 안에서 해결하고 못 맞추면 수치와 이유를 표로 보고. 전/후 `render-stats.csv`.
