## 무인 진행 규칙
1. **사용자에게 묻고 기다리지 않는다.** 판단이 필요하면 가장 합리적인 기본값으로 진행하고, SETUP-REPORT.md 맨 아래 "사용자 결정 대기" 표에 질문·고른 기본값·되돌리는 방법을 적는다.
2. 막힌 단계(로그인·결제·외부 다운로드 실패 등)는 건너뛰고 기록한 뒤 다음 단계를 한다.
3. 2~3단계마다 커밋·push한다. 사용량 한도로 멈췄다가 재개하면 이 파일 → SETUP-REPORT.md "현재 단계" → `git status`·`git log` 순서로 확인하고 끝난 것은 건너뛴다.
4. SETUP-REPORT.md "현재 단계" 표는 이 순서로 유지하고, 항목이 끝날 때마다 갱신한다.
5. 사용자가 아침에 바로 볼 수 있게, SETUP-REPORT.md 맨 위에 "밤사이 요약" 절(한 일, 시안 이미지 경로, 남은 문제, 사용자가 할 일)을 만들고 항목마다 갱신한다.
6. 보안 규칙: 결제·구독 변경 금지, Photon 대시보드 변경 금지(100 CCU 활성화 금지), 비밀번호·토큰 입력 금지, 사용자 폴더 밖 삭제 금지, UAC 금지.
