# 온라인 대전 직접 시험하기 (폰 + PC)

폰(APK)과 PC(Unity 에디터)가 같은 방에서 1대1을 하는 순서입니다. 두 기기 모두 **같은 버전**이어야 합니다(버전이 다르면 방에 못 들어갑니다).

## 준비

- [ ] PC: `Game` 프로젝트를 Unity로 엽니다. 최신 코드인지 확인(`git pull`).
- [ ] 폰: 같은 코드로 만든 APK를 설치합니다(`Builds/FactoryWars-dev.apk`). 예전 APK면 버전이 달라 입장이 거부됩니다.
- [ ] 두 기기 모두 인터넷 연결(와이파이·LTE 상관없음). 서버는 Photon 서울(kr) 지역입니다.

## 순서

1. PC: `Assets/QuantumUser/Scenes/Menu.unity`를 열고 ▶(Play).
2. PC: **온라인 방 코드 대전** → 진영·색 고르기 → **방 만들기**. 화면 위에 `방 코드 XXXXXX`가 나옵니다.
3. 폰: **온라인 방 코드 대전** → 진영·색 고르기 → 코드 칸에 6자리 입력 → **코드로 참가**.
   - [ ] 두 화면 모두 대기실에 두 사람이 보인다.
   - [ ] 화면 위 `버전 FW3-…`가 두 기기에서 같다.
4. 폰: **준비**. PC(방장)의 **대전 시작** 버튼이 켜집니다.
   - 방장은 모드(1대1·자유·2대2), 봇 수, 난이도, 휴전 시간을 바꿀 수 있습니다. 빈자리는 봇으로 채울 수 있습니다.
5. PC: **대전 시작**. 두 기기 모두 경기 화면으로 넘어갑니다.
   - [ ] 두 기기의 본진이 대각선 자리다.
   - [ ] 한쪽에서 유닛을 움직이면 다른 쪽 화면에서도 같은 곳으로 간다(약 0.2초 늦게).
6. 끊김 시험: 폰을 비행기 모드로 30초 두었다가 끕니다.
   - [ ] PC 화면 위에 `플레이어 2 연결 대기 NN초`가 보이고, 그동안 폰 쪽 기지는 AI가 움직인다.
   - [ ] 비행기 모드를 끄고 앱으로 돌아오면 같은 경기로 다시 들어간다(60초 안).
   - [ ] 60초가 넘으면 폰 쪽이 기권 처리되고 PC가 승리한다.
7. 기권 시험(선택): **메뉴 → 기권 → 다시 누르기**. 상대 화면에 승리가 뜬다.

## 문제가 생기면

- "게임 버전이 다릅니다": 두 기기의 코드가 다릅니다. 같은 커밋으로 APK를 다시 만드세요.
- "그 코드의 방이 없습니다": 코드를 잘못 입력했거나 방장이 나갔습니다.
- 디싱크(화면이 서로 다름): 개발 빌드는 1초마다 상태를 비교합니다. 다르면 오류 로그와 함께 덤프 파일이 남습니다.
  - PC: `%USERPROFILE%\AppData\LocalLow\<회사>\<제품>\desync\`
  - 폰: `Android/data/<패키지>/files/desync/`
  - 오류 로그: 같은 위치의 `logs/errors-날짜.txt`
- 이 파일들을 Claude에게 주면 원인을 찾습니다.

## 자동 시험 (Claude가 돌리는 것)

`-testCategory Online`: 한 PC에서 클라이언트 둘을 실제 Photon 서버에 붙여 방 만들기 → 참가 → 대기실 → Quantum 온라인 세션 → 30초간 체크섬 비교. 결과는 `Game-logs/online/online-tests.log`.
