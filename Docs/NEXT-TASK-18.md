# 항목 18 — 구불구불한 강 + 개폐식 방어 울타리

시작 조건: 항목 14~17이 모두 커밋·push된 뒤에 시작한다. 아직 남은 항목이 있으면 그것부터 끝낸다.
CLAUDE.md 규칙과 결정론 유지, 전체 테스트(PlayMode 포함) 통과 필수. 사용량 한도 규칙대로 2~3단계마다 커밋·push.
항목 17(맵 확장)이 끝난 새 맵 기준으로 작업한다.

먼저 아래 계획이 현재 코드와 맞는지 확인하고, 다르면 SETUP-REPORT.md에 차이와 수정안을 적은 뒤 진행해.

현재 구조(확인됨):
- 강의 이동 차단 = 다리와 일직선인 직각 Hill 직사각형 (FactoryWarsSetup.cs 맵 정의, Orbit 대칭 복제)
- 강 그래픽 = TerrainKit.MoatRects가 땅에 직사각형 구멍 + 물 면 + 수직 벽 (폭 7m 고정)
- 휴전 = NavMesh 구역 "Bridges"를 7:00에 켬 (TruceSystem.SetBridges), IsReachable/BaseAreas로 휴전 중 본진 밖 제한
- 다리 연출 = WorldView에서 -78°→0° 회전

## 1. 구불구불한 강
- 강 경로는 에디터 맵 생성 단계에서만 계산(고정 시드 사인파 + 결정론적 노이즈)하고, 결과를 짧은 회전 사각 조각들의 띠(MapShape 배열)로 맵 데이터에 저장한다. 경기 중 런타임 계산 금지.
- 한 사분면만 만들고 기존 Orbit으로 복제해 2P 점대칭, 4P 90° 회전 대칭 유지.
- 제약(전부 EditMode 테스트로 검증):
  a) 다리 중심 앞뒤 10m는 직선, 그 바깥으로 곡률을 부드럽게 증가
  b) 본진 쪽 강가는 BaseAreas 경계 밖에만 있음 → 본진 건설 가능 면적이 항목 17 결과와 같거나 더 넓음(수치 비교)
  c) 강폭은 최소 6m, 최대 10m 범위에서만 변화. 어느 지점도 지상 유닛이 건너지 못함
  d) 다리 위치·개수는 항목 17과 동일
- 그래픽: MoatRects 직사각형 파기를 강줄기 리본 메쉬로 교체(물 면 + 흙·모래색 경사 강변 띠 + 작은 바위). 장식 바위는 차단 영역 안에만 배치. 팔레트·단일 서브메쉬·SRP Batcher 규칙 유지.

## 2. 개폐식 방어 울타리
- 시뮬레이션: 기존 "Bridges" NavMesh 구역을 "Barrier"로 이름만 바꿔 그대로 재사용. 다리는 항상 내려진 통로이고, 휴전 중에는 다리 입구의 Barrier 구역이 막혀 있다가 TruceEndFrame에 열린다. IsReachable, 휴전 중 건설 제한 등 기존 휴전 규칙은 유지. 이벤트 이름은 BarrierOpened로 정리(테스트·HUD·AI 참조 함께 수정).
- 울타리 배치: 각 다리 양쪽 입구 + 강가를 따라 입구 좌우 약 10~15m씩. 강 전체를 두르지 말 것(성능).
- 메쉬(절차적 로우폴리): 묵직한 금속 기둥 + 가로 패널, 기둥 위 경고등. 경고등 색은 적색으로 하고, visual-style 기능색 규칙에 "경고 = 적색"을 추가(주황은 쇳물·화염 전용 유지). 팀 컬러는 패널 테두리에만.
- 연출(View 전용, 시뮬레이션 상태만 읽기):
  - 휴전 중: 경고등 느린 점멸
  - 종료 10초 전(TruceEndFrame 기준): 빠른 점멸
  - 7:00: 상단 알림 "전쟁 시작 - 방어 울타리가 해제됩니다!"(Texts에 추가), 울타리가 1.7초 동안 부드럽게 땅속으로 하강 후 비활성화, 바닥 먼지 파티클(low 품질에서는 끔)
- 기존 다리 세움·회전 연출은 제거.
