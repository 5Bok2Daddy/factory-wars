# 항목 17B — 맵을 하나로: 4인 맵에서 2~4명이 대전

시작 조건: 지금 하던 19C를 커밋·push한 뒤 바로 한다. 19D·24·22·23보다 먼저 한다. 이후 모든 작업은 이 결정을 따른다.
CLAUDE.md 규칙과 결정론 유지, 전체 테스트 통과 필수. 단계마다 커밋·push.

## 사용자 결정 (2026-11-08)
2인 맵과 4인 맵을 나누지 않는다. **4인 맵 하나**만 두고, 2명이 참가하면 그 맵에서 2인 대전이 되게 한다.

## 1. 자리 배치
- **2명:** 서로 **대각선** 자리. 4인 맵은 90도 대칭이라, 대각선 두 자리는 180도 회전으로 정확히 같은 조건이다. 이웃한 두 자리는 쓰지 않는다.
  - 대각선 쌍(0·2 또는 1·3)은 방 시드로 결정론적으로 고른다. 화면에는 "북서·남동"처럼 보여 준다.
- **3명:** 허용한다. 빈자리 하나가 생겨 자리마다 조건이 조금 다르다. 방 화면에 "3인은 자리 유불리가 있을 수 있음"을 한 줄로 알린다. 자리는 무작위(시드)다.
- **4명:** 지금과 같다. 2대2 동맹 프리셋도 그대로 쓴다. 2대2는 대각선끼리 같은 편이 기본이고, 방장이 바꿀 수 있다.
- 빈자리를 봇으로 채우는 기존 기능은 유지한다. 방장이 "빈자리 비우기 / 봇 채우기"를 고른다.

## 2. 빈 본진 자리 = 중립 대형 확장
- 비어 있는 본진 자리에는 사령부를 만들지 않는다. 그 자리는 **중립 대형 확장지**가 된다.
  - 자원: 철 2 + 숲 1. 매장량은 본진의 70%(임시값). 너무 크면 먼저 먹는 쪽이 일방적으로 유리해지기 때문이다.
  - 그 자리의 운하·다리는 그대로 두고, 휴전 울타리와 수문(24번 이후)은 경기 시작부터 열어 둔다. 단, 휴전 중에는 "자기 본진 밖 이동 금지" 규칙 때문에 아무도 들어갈 수 없다.
- 2인 대전에서는 빈 자리 두 곳이 모두 두 플레이어에게서 같은 거리다(대각선 배치라서). 측정해서 확인한다.
- AI 확장 후보에 빈 본진 자리를 넣는다. 가치가 높게, 단 중반 이후에.

## 3. 2인 맵 제거
- `Map2P` 맵 정의·에셋·NavMesh·화면 분기를 지운다. 2인 전용 테스트는 "4인 맵 2명 대각선"으로 바꾼다. 맵 선택 UI가 있으면 없앤다.
- 지금까지의 2인 맵 측정값 표는 보고서에 기록으로 남긴다(비교용).
- 항목 17 측정을 **4인 맵 2명 대각선** 기준으로 다시 잰다.
  - 사용 영역
  - 본진 → 상대 본진 이동 시간: 중앙 길 / 측면 길(이웃 빈자리 경유)
  - 본진 → 빈 본진 자리 이동 시간
  - 양쪽 차이 0초 확인
- 2인 대전의 경기 시간 목표는 10~15분이다. 맵이 넓어져 길어지면 원인을 기록한다(조정은 항목 22에서).

## 4. 다른 항목에 미치는 영향 (각 파일보다 이 절이 우선)
- **19C·19D(그래픽):** 2인 맵 화면은 만들지 않는다. 비교 화면의 고정 시점은 4인 맵 기준으로 다시 고른다(본진, 다리, 중앙, 전체, HUD).
- **21(도시):** 도시 건물·쓰러지는 건물·진지 배치는 4인 맵 기준만 유지한다.
- **24(해군):** 외곽 수로는 4인 맵 하나에만 만든다. 2인 대전에서는 빈 본진 자리의 물가가 해상 쟁탈 지점이 된다.
- **22(밸런스):** AI 대전은 "4인 맵 2명 대각선" 20판(자리 교대)과 "4인 맵 4명" 20판으로 잰다. 2명일 때 자리 쏠림은 0·2 쌍과 1·3 쌍을 모두 잰다.
- **23(실기기):** 빠른 시작 버튼은 "2인 대전(4인 맵)", "4인 대전" 두 개로 한다.

## 5. 테스트
- 2명 대각선 배치가 결정론적이다.
- 빈 본진 자리는 중립 확장이고 사령부가 없다.
- 빈 자리 거리가 대칭이다.
- 3명 배치가 동작한다.
