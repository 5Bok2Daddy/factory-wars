# 항목 23 — 실기기 시험 준비와 새 APK

시작 조건: 항목 22가 push된 뒤.
이 항목이 끝나면 push하고 **멈춘다.** 다음은 사용자의 실기기 확인 결과를 보고 정한다(챕터 4 온라인 대전 예정).

## 1. 폰에서 확인하기 쉬운 장치
- **성능 오버레이:** FPS, 프레임 시간, 그리기 호출, 유닛 수, 품질 단계를 표시한다. 설정 메뉴에서 켜고 끌 수 있고, 개발 빌드에서만 보인다.
- **품질 자동 선택:** 첫 실행 때 기기 성능(GPU 이름, 메모리, 첫 10초 평균 FPS)으로 low·medium·high를 고르고, 설정에서 바꿀 수 있게 한다.
- **시험용 빠른 시작:** 메인 메뉴에 개발 빌드 전용 버튼을 둔다.
  - "AI 대전 바로 시작(2인·4인)"
  - "휴전 0분"
  - "대규모 교전 장면 불러오기"(19A 고정 장면)
- **기록 저장:** 경기마다 평균·최저 FPS, 최대 그리기 호출, 메모리를 기기 안 파일(Application.persistentDataPath)에 CSV로 남기고, 설정에서 "기록 공유" 버튼으로 내보낼 수 있게 한다.

## 2. 터치 조작 점검 (에디터 기기 시뮬레이터)
- 화면 크기: 6.1인치 1080×2400, 6.7인치 1440×3200, 태블릿 비율
- 확인 항목: 버튼 최소 크기(물리 9mm 이상), 노치·제스처 바 안전 영역, 한글 글꼴 크기, 진지 들어가기·건물 공격·낙하 구역 경고가 손가락으로 조작 가능한지
- 문제는 고치고 기기별 캡처를 `screenshots/device/`에 저장한다.

## 3. 새 APK
- 중간 산출물을 지우고 깨끗하게 개발 APK를 빌드해 `Builds/FactoryWars-dev.apk`로 둔다(크기 기록).
- 에디터에서 같은 장면의 low·medium·high 프레임 시간 추정치를 기록한다.

## 4. 사용자 확인용 체크리스트

2. 2인 AI 대전 한 판: 조작감, 버튼 크기, 글꼴, FPS
3. 대규모 교전 장면: 최저 FPS, 발열
4. 기록 공유 버튼으로 CSV 보내기
5. 느낀 점 메모 칸
