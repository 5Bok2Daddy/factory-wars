권장 모델: **Fable 5.2**(시뮬레이션 설계 비중 큼). 33이 끝난 뒤, 그리고 에셋 들여오기(32-0·1)가 끝난 뒤 시작한다. 패키지가 없으면 절차 모델로 진행하고 칸만 만든다.

## 설계 핵심: 네 기능은 "시야"로 맞물린다
| 기능 | 시야에 의존하는 방식 |
|---|---|
| 전장의 안개 (A) | 모든 기능의 기반. 보이는 곳에만 공격·작전 지시 가능 |
| 보급품 알람 (B) | 안개 속이어도 "구역"만 알려 줌 → 병력을 보내 시야를 열어야 정확한 위치·쟁탈 가능. 낙하 시 신호탄이 잠깐 모두에게 시야를 줌 → 항공 작전이 가능해지는 순간 |
| 저격수 (C) | 주둔 시 넓은 시야(정찰 역할) + 은신 잠입으로 적 자원지 시야 확보 → 그 시야로 항공 작전 호출 |

## A. 전장의 안개 (시뮬레이션)
- 격자: 4m 칸(맵 360m → 90×90). 플레이어별 `Visible`(지금 보임)·`Explored`(본 적 있음) 비트 배열. **5틱(0.25초)마다** 갱신, 틱당 처리 상한(데이터).
- 시야 원천과 반경(전부 `UnitSpec.SightRange`·`BuildingSpec.SightRange` 데이터): 보병 10, 차량 9, 정찰 버기·척후 오토바이 16, 정찰선 18, 헬기 14, 건물 8, 레이더 기지 40, 주둔 보병 +6, 주둔 저격수 26, 고지대 +4, 보급 신호탄 15(20초, 모든 플레이어).
- 동맹은 시야 공유(외교 상태 연동). 관전·리플레이는 전체.
- 기존 고지대 은폐(`IsVisibleTo`)는 "칸이 보임 AND 은폐 아님"으로 합친다.
- 규칙: 자동 표적·공격 명령·항공 작전 지시는 **보이는 적·보이는 칸**에만. 안 보이는 칸 탭 → 거부 사유 "시야 없음".
- 화면: 안개 셰이더(미탐색 검정, 탐색됨 회색 + 마지막으로 본 건물 잔상, 보임 맑음), 미니맵 동일. 성능: 안개 텍스처 90×90 R8 1장, GPU 블러.
- 알려진 한계: lockstep이라 모든 클라이언트가 전체 상태를 가진다(맵핵 가능). 보고서에 적고 이번엔 대응하지 않는다.
- 시험: `Fog_VisibleOnlyNearOwnAndAllied`, `Fog_ExploredPersists`, `Fog_AttackRejectedOutsideVision`, `Fog_HighGroundConcealmentStillApplies`, `Fog_DeterministicOnline`.

## B. 보급품 사전 알람
- 기존 `DropIntervalSeconds`·`DropWarningSeconds`·`SupplyDropIncoming`을 확장한다.
- 낙하 지점: 맵 데이터 `SupplyZones`(후보 구역 목록) 중 `frame.RNG`로 구역 선택 → 구역 안 정확한 지점도 그때 RNG로 정하지만 **처음엔 숨긴다**.
- 단계별 공개(시간은 데이터):
  | 낙하까지 | 공개 정보 |
  |---|---|
  | 35초 | 반경 30m 경고 원(안개 위에 그림) + 미니맵 레이더 파동 + 경고음 |
  | 10초 | 원이 반경 10m로 좁아짐(정확 지점 근처) + 빨라지는 경고음 |
  | 0초 | 낙하산 착지, 신호탄 연기 → 반경 15m를 **모든 플레이어에게 20초 공개** |
- 획득: 보병·차량이 상자 3m 안에 5초 머물면 획득. 적이 같은 반경에 있으면 진행 멈춤(쟁탈). 저격수는 획득 불가.
- 보상(가중치 데이터): 자원 묶음 / **긴급 출격권**(항공기 하나 즉시 재정비) / **정찰 사진**(적 본진 15초 공개) / 보급(주변 보병 회복).
- UI·소리·진동: 화면 밖이면 가장자리 화살표 + 남은 초. 레이더 파동은 2초마다(10초 이후 1초). `AudioCatalog` 칸 `drop_warning`, `drop_closing`, `drop_landed`, `drop_captured`. 진동은 35초·0초 짧게. 알림 탭 → 카메라 이동.
- AI: 경고를 받으면 구역 근처 시야용 정찰 → 병력 급파, 신호탄 시야가 열리면 쟁탈 중인 적에게 항공 작전.
- 시험: `Drop_ZoneAnnouncedBeforeExactPoint`, `Drop_FlareRevealsToAll`, `Drop_ContestedPausesCapture`, `Drop_RewardTableDeterministic`.

## D. 정찰 연동 비조작 항공 작전 (Sortie)
### 운용
- 비행장에 **격납 칸 4개**(데이터). 생산된 전투기·공격기·수송기는 칸에 대기, 직접 이동 조작 불가.
- 헬기(호크·돌풍)는 지금처럼 직접 조작하는 유닛으로 남긴다. 헬기장도 그대로.
- 기존 **스카이포트리스 폭격기는 작전기(폭격)로 전환**한다. 대륙 연방에도 같은 3종 작전기를 진영별 수치로 준다.
| 작전기 | 단계 | 작전 | 재정비 | 비고 |
|---|---|---|---|---|
| 전투기 | 2 | 기총소사 | 45초 | 소형·보병에 강함, 차량에 약함 |
| 공격기 | 3 | 폭격 | 90초 | 건물 피해 2배(가건물 철거), 대형 유닛 상한 공유 |
| 수송기 | 2 | 공수 투하 | 120초 | 병력(인구 6까지, 병영에서 탑재 지정) 또는 보급 상자 1개 |
- 출격마다 작은 비용(철·강철 데이터) + 비행장 전기 유지비.
### 지시 (명령 `OrderSortie(slot, target, heading)`)
- 목표 지점은 **지금 보이는 칸**(자기·동맹 시야, 신호탄 포함)이어야 한다. 아니면 거부 "시야 없음".
- 진입 방향은 자유. 모바일 조작: 작전기 아이콘 탭 → 목표 탭(안 보이는 곳은 빨간 X) → 드래그로 진입 화살표 → 확인. 경로 미리보기에 **알려진 적 대공 범위**를 빨갛게.
### 결정론 비행 궤적 (FP, 물리 없음)
- 출격 시 점들을 한 번 계산해 컴포넌트에 저장: 비행장 A → 진입점 E = T − d·Lin → 타격점 T → 이탈점 X = T + d·Lout → 귀환 선회점 R → A. (d = 진입 방향 단위 벡터, Lin·Lout·선회 반경·속도는 데이터)
- 위치는 **출격 프레임 기준 경과 프레임 × 속도로 구간 누적 거리**를 따라 계산(구간별 FP 길이 미리 계산). 회전은 구간 방향. 화면은 보간·선회 기울기만(33·32의 VisualProfile).
- 기총소사: E→X 구간에서 k틱마다 현재 위치 중심 폭 w 직사각형(통로) 안 적에게 피해(보병 위주).
- 폭격: T를 중심으로 간격 s로 n발 투하 프레임을 미리 계산 → 낙하 지연 후 착탄, 반경 피해 + 건물 배율.
- 공수 투하: T 상공 통과 프레임에 탑재 유닛 생성, 낙하 4초 동안 무적·행동 불가, 착지 위치는 반경 안 `frame.RNG` 흩뿌림. 보급 상자면 B의 상자 생성.
- 피격: 작전기는 체력이 있고 대공(대공차·방공포대·스카이가드·항모 드론)이 사거리 안에 있을 때 쏠 수 있다. 격추되면 남은 탑재·폭탄은 사라지고 칸은 비며 재생산 필요. 적 시야에 들어온 작전기는 적에게 경고.
### AI
- 작전 표적 우선순위(데이터): 주둔 저격수 건물 > 쟁탈 중 보급 > 포병·다연장 > 밀집 보병 > 확장 기지 공병. 시야가 없으면 정찰 유닛을 먼저 보낸다. 알려진 대공 범위는 진입 방향으로 피한다.
### 시험
`Sortie_RejectedOutsideVision`, `Sortie_PathIsDeterministicFromStartFrame`, `Sortie_StrafeHitsCorridorOnly`, `Sortie_BombDestroysShackAndEjectsSniper`, `Sortie_AirborneDropLandsCargo`, `Sortie_ShotDownLosesPayload`, `Sortie_ReturnsAndRearms`, `Sortie_DeterministicOnline`, `Ai_ScoutsThenCallsSortie`.
