# Factory Wars 프로젝트 상태

## 2026-11-20 전장 사운드

- 로컬 제공본 11개 중 9개 음원을 편집했다. 전투 단발 5개와 전차·로터·항공·전투 배경 루프를 화면 위치와 움직임에 맞춰 섞는다. Unity GPU PlayMode **13/13 통과**. 전차 출발과 정차 페이드, 단발 재생 제한, 카메라 밖 감쇠를 확인했다.
- 일부 원본의 배포 조건 확인과 Android 청취가 남아 있다. 사막·해안용 신규 구매 후보를 에셋 검토 목록에서 뺐다. [로컬 대시보드](../../README.md)

## 2026-11-20 조명·표면과 HUD

- 기본 조명, 지면 굴곡, 수면 잔물결 반사, 높음의 가장자리 보정을 개선했다. 대형 항공기의 선택 링, 용접 효과, 터치 버튼과 방어·지원 메뉴도 수정했다.
- Unity GPU 집중 검사 **22/22 통과**. 기본 맵 5개 검사와 보병 달리기·대기·엄폐, 기초 공사에서 골조 상승 및 완공으로 이어지는 동작이 포함된다. 직전 전체 실패 34개 중 10개 항목을 집중 검사에서 다시 통과했다. Android 프레임 시간과 최신 전체 회귀는 확인 대기다. [로컬 대시보드](../../README.md)

## 2026-11-20 조선소·활주로와 맵 겹침

- 조선소 수상 건조, 인접 활주로·착륙장 공병 시공과 생산 잠금, 바리케이드 붕괴를 구현했다.
- 기본 5개 맵을 로드해 길가 소품과 배경 프리팹 배치를 검사했다. Unity GPU PlayMode 관련 검사 21/21 통과. 전체 회귀에서 신규 실패 0건, 기준선 실패 34건이다. Android 및 온라인 경기는 확인 대기다. [대시보드와 화면](../../README.md)

## 2026-11-20 로컬 최신 상태

- Unity PlayMode 집중 검사 13/13 통과. 노드 직결 채굴과 공병 건설, 사령부 컨베이어, 공장 단계별 외형·생산 효과, 공장 관리와 도크린을 확인했다.
- 자유 연방 보병 무장 공장의 Lv.1~3 외형과 공장 관리·도크린을 GPU로 캡처했다. [로컬 대시보드](../../README.md)
- 기존 전체 회귀 기준선에 실패 38건이 있다. Android 실기기와 온라인 경기 포함 최신 전체 상태는 추가 검증이 필요하다.

2026-11-19 인수 기준. Unity 6000.0.85f2와 Photon Quantum 3.0.14 기반 모바일 RTS다. Git 저장소는 작업 루트의 `Game/`이며 인수 시 `main` HEAD는 `efd28dc`였다.

## 완료 기록

- [기존 인계표](../../SETUP-REPORT.md#현재-단계-재개-기준)에 TASK-32~37 완료가 기록돼 있다.
- 빌드 설정에서 메뉴와 Map4P, MapDesert, MapUrban, MapArchipelago, MapStrait를 확인했다.
- 이전 PlayMode 로그에는 54건 중 50건 통과와 실패한 네 건의 후속 통과가 기록돼 있다. 인수 작업 트리의 결과는 [인계 기록](HANDOVER.md)을 기준으로 한다.

## 구현됐으나 인수 시 재검증 대기

- Synty 에셋 연결, War FX 및 기지 작업자 연출, 신규 시각·건설 단계 검증 케이스.
- 인수 시 추적 파일 27개 수정과 미추적 소스·메타 4개가 있었다. 변경 내역은 Git 작업 트리에 보존한다.

## 진행 중

- 자원 노드 직결 제재소·철 채굴 공장의 배치, 공병 배치·퇴거, 자원 생산과 HUD를 연결했다. 데이터 생성, 철 채굴 집중 PlayMode 2/2 및 GPU 캡처 1/1이 통과했다. 제재소 경기 흐름, 작업자 애니메이션, 모바일 성능, 실서버 전이는 별도 검증 대기다.
- 기준선 PlayMode에서 실패 38건이 확인됐다. 원인과 재현 범위는 조사 중이다.
