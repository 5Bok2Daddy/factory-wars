## 1. 유닛 분류: 소형 · 중형 · 대형 (진영마다 3 / 3 / 2 + 해군 2)
| 진영 | 소형 (병영, 1단계) | 중형 (군수공장·비행장, 2단계) | 대형 (중공업 기지·비행장, 3단계) |
|---|---|---|---|
| 자유 연방 | 레인저 분대, 스카이가드 분대, **새: 정찰 버기(군수공장)** | 이글 전차, 호크 공격헬기, **새: 야전 지원차(수리·연막 중 하나)** | 스카이포트리스 폭격기, **새: 중전차(중공업 기지) — B1 해결** |
| 대륙 연방 | 민병대, 화염방사 분대, **새: 척후 오토바이(군수공장)** | 용린 전차, 천둥 대공차, **새: 공격헬기(비행장) — B2 해결** | 만리 다연장포, **새: 요새 전차(중공업 기지)** |
| 공통 해군 | 정찰선(소형) | 포격함(중형) | — |
- 새 유닛 이름은 가칭이다. **실존 무기 이름·형태를 닮지 않게**(기존 규칙) 짓고 SETUP-REPORT에 표로 남긴다.
- 크기 규칙(데이터 `GameRulesSpec`에 둔다): 소형 = 싸고 빠름·인구 0.5~1, 중형 = 주력·인구 2~3, 대형 = 비싸고 느림·인구 5~6·진영당 동시 보유 상한(예 4).
- 상성 한 줄에 크기를 넣는다: 예) 화염 → 소형에 강함, 대장갑 → 중·대형에 강함. 기존 `AttackType` 상성과 겹치면 기존 것을 유지하고 크기 보정만 데이터로 더한다.
- 새 유닛은 `VisualCatalog`에 칸을 추가한다(지금은 절차 모델·자동 아이콘). `ASSET-SWAP.md` 칸 목록을 갱신한다.

## 2. 테크 단계 (스타크래프트식 본진 등급)
- **기지 1단계 (시작):** 사령부·발전소·집하장·보급창·병영·가공소·방어탑 → **소형**
- **기지 2단계 "연대 본부"**: 사령부에서 업그레이드(비용·시간 데이터, 연구소 필요). 업그레이드 중에도 사령부 기능 유지. → 군수공장·비행장·조선소·방공포대 → **중형**
- **기지 3단계 "사단 본부"**: 2단계 + 중공업 기지 필요(또는 연구소 2개 중 택1 — 데이터로). → 대형, 비행장의 대형 유닛
- 구현: `BuildingSpec.RequiredTier`, `UnitSpec.RequiredTier`(데이터), 플레이어 상태에 `BaseTier`(.qtn), 명령 `UpgradeBase`. 사령부가 여러 개면 가장 높은 등급. 등급 사령부가 모두 파괴되면 등급도 내려간다(데이터로 켜고 끄기).
- **연구소 연구 (B3 해결)** — 크기별 업그레이드:
  - 소형·중형·대형 각각 **공격 +1/+2**, **방어 +1/+2** (2단계는 기지 3단계 필요). 연구 중 전기 소모(`WhileResearching`).
  - 진영별 "정예화" 연구 1개씩(소형 1종을 강화형으로: 체력·사거리 등 데이터 보정 + 화면에 계급 표시). 기존 유닛에도 즉시 적용.
- 휴전 7분 동안 1→2단계까지 갈 수 있게 비용·시간을 맞춘다(목표: 7분 시점에 소형 위주 + 2단계 진행 중).
- AI(`BotSystem`, `AiSpec`): 단계 업그레이드 시점, 연구 우선순위, 크기 구성 비율을 데이터로. 쉬움은 3단계에 늦게 가게.
- 시뮬레이션 규칙: FP만, 금지어 0건, 결정론 시험 통과.

## 3. 사용자 UI 정리 (가장 눈에 띄는 부분)
목표: "회색 기본 버튼이 흩어진 화면" → **스타크래프트식 4구역 + 깔끔한 모바일 카드**.
### 3-1. 화면 구역 (16:9~21:9, 안전 영역 적용)
| 구역 | 내용 |
|---|---|
| 상단 왼쪽 | 자원 한 줄(철·목재·강철·전기 저장/한도·인구). 아이콘 + 숫자, 부족하면 빨강 깜빡임 |
| 상단 가운데 | 휴전 남은 시간·경고 알림만. **없으면 아무것도 그리지 않는다**(빈 막대 제거) |
| 상단 오른쪽 | 아이콘 버튼 2개: 외교, 메뉴(설정·기권 포함). 글자 버튼 제거 |
| 하단 왼쪽 | 미니맵 + 그 옆 작은 아이콘 버튼 세로 줄: 유휴 공병(숫자 배지), 전체 군대, 부대 1·2·3(지정은 길게 누르기) |
| 하단 가운데 | **선택 카드**: 1개 선택 → 아이콘·이름·**크기 배지(소/중/대)**·체력 막대·공격/방어 업그레이드 단계. 여러 개 → 종류별 아이콘 + 개수, 탭하면 그 종류만 선택 |
| 하단 오른쪽 | **명령 카드 3×3**: 선택에 따라 바뀜. 유닛: 이동·정지·위치 고수·순찰·공격 이동·특수 기능. 공병: 건설 → 탭 3개(기본 / 2단계 / 3단계) 하위 메뉴. 건물: 생산(대기열 5칸) · 연구 · 기지 업그레이드. 빈 칸은 비워 둔다 |
- 범위 선택은 명령 카드 대신 화면 가장자리 작은 토글 하나로.
- 잠긴 항목: 회색 + 자물쇠 + 길게 누르면 "기지 2단계 필요 / 군수공장 필요" 같은 이유. 현재 단계보다 2단계 이상 높은 것은 숨긴다.
- 좌상단 빈 어두운 상자의 정체를 찾아 고치거나 지운다(알림 영역이면 비었을 때 숨김).
### 3-2. 스타일은 데이터로 (나중에 산 UI 팩으로 교체)
- `UiTheme` 에셋: 색(패널·글자·강조·진영색·경고), 모서리 둥글기, 글자 크기 3단계, 간격, 버튼 최소 크기(9mm).
- `UiCatalog` 칸(VisualCatalog처럼): 패널, 버튼(보통·누름·비활성), 아이콘 테두리, 자원 아이콘 5, 크기 배지 3, 체력 막대, 미니맵 테두리, 탭, 툴팁. **비면 지금 그림**. 9-slice 스프라이트.
- 임시 그림: `temp-assets/ui-pack-sci-fi`(Kenney, CC0) 형태 + UiTheme 색으로 다시 칠함.
- 글꼴: Pretendard 또는 Noto Sans KR (SIL OFL, 무료). 사용자가 `temp-assets/`에 넣지 않았으면 **다운로드하지 말고** "사용자가 할 일"에 적고 기존 글꼴 유지.
- 유닛·건물 아이콘은 모델에서 자동 촬영(고정 각도·투명 배경)해 만든다. 에셋 팩 교체 후 메뉴 한 번으로 다시 찍을 수 있게.
- `Game/Docs/UI-SWAP.md`: UI 팩을 넣고 칸에 연결하는 순서.
### 3-3. 시험
- `Ui_PanelsDoNotOverlap`(기존) + `Ui_TextFitsAllButtons`(글자 넘침 0) + `Ui_TouchTargetsAtLeast9mm` + `Ui_NoEmptyVisiblePanels`(빈 패널 표시 0) — 해상도 3종.
- 전/후 캡처: `screenshots/ui/31_before_*.png`, `31_after_<해상도>_<상황>.png`(공병 선택, 건물 선택, 여러 종류 선택, 잠금 툴팁). **파일 해시가 서로 달라야 한다**(같은 그림 재사용 금지).
