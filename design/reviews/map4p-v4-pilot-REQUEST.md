# Map4P v4 시범 교차 검수 요청

**검수 범위**는 640m 표준 4인 맵의 모서리 본진 1세트와 16×16m 시가지 블록 기본형·변형 2개다. 중앙 요새, 경계 건물 열, 외곽 거점 등 승인 대기 중인 유형은 칸 지도 위치와 통행만 판정하고 완성 외형 점수는 보류한다.

## 판정 전 확인

- 게임 카메라 스크린샷 다섯 장은 휴전이 풀린 뒤 촬영했다. 시야 높이는 본진 근접 62m, 광각 108m, 도시 근접 35m, 도로변 62m, 요새 155m다.
- 집중 PlayMode 10건이 통과했다. 휴전 뒤 전차 4대는 54.15~56.25초에 도착했다. 승인 CSV 전 칸의 수로·다리 점유와 지상·수상 통행을 대조했다.
- 겹침, 뜸·박힘, 도로·채집로·건설 부지 침범은 0건이다. 30% 제한에 대한 최대 단색 묶음은 도시 근접의 22.4%다. 정상 건설 부지를 제외한 본진 빈 구역은 기준 12m에 대해 24m로 실패했다.
- 시범 전체 렌더러 4,583개·삼각형 2,569,443개다. 도로변 화면에서 절두체와 교차하는 시범 렌더러는 282개·삼각형은 145,132개다. 그리기 호출과 Android 성능 판정은 대기 중이다.
- 가장 먼저 본진 차량장 쪽 빈 구역과 경사로 접합부를 본다. 16개 P 칸의 지상 통행은 확인했지만 생성된 시각 경사 면은 본진과 변을 공유한 네 칸만 덮어 턱처럼 보인다. 시가지 외벽·차량 색 반복도 확인한다. 이전 캡처와 검사 원본은 PC의 `screenshots/map4p-v4/`, `Game-logs/map4p-codex-v5.xml`, `Game-logs/map4p-codex-ramp-occupancy.json`에 있다.

검수자는 각 적용 항목에 0점(미충족), 1점(부분 충족), 2점(충족)과 근거 화면을 기록한다. 전체 맵 기준은 22점 중 18점 이상과 금지 항목 0건이다. 보류 항목에 대한 점수는 외형 구현 후 매긴다.

겹침·뜸/박힘·채집로/도로/건설 침범·반복 배열·단색 바닥 30% 초과·8기 규모 빈 구역·마젠타/흰 임시 도형을 확인한다. 결과에는 가장 먼저 수정할 촬영 구도 또는 블록과 판정 근거를 남긴다. 남은 11종 블록 제작은 사용자 승인 후 시작한다.

## PC 재현

Unity 6000.0.85f2에서 로컬 POLYGON City·Military를 불러온 상태로 **Tools → Factory Wars → Map4P v4 → Build Pilot Blocks**, 이어서 **Bake Map4P Only**를 실행한다. 그래픽을 켠 PlayMode에서 `FactoryWars.Tests.LocalMatchTests.Map4P_CaptureTopAndGameplayViews`를 선택해 실행한다. `FW_MAP_ITER=review`를 지정하면 PC의 `screenshots/map4p-v4/`에 새 파일이 저장된다. 생성된 프리팹과 구입 에셋은 로컬에 둔다.
