# 향후 게임플레이 단계 설계 메모 — 물류·유닛 (2026-11-22 사용자 지시 보존)

> **상태: 보존만 함. 구현 금지.** Map4P v4 맵 관문(교차 리뷰 + 사용자 승인)을 통과하기 전에는 시스템·시험을 바꾸지 않는다.
> 구현할 때는 결정론 규칙(FP·커맨드·AssetObject 수치)을 따른다.

## 1. 본진 자원 흐름
- 본진의 채집·가공 건물에서 나온 자원은 **컨베이어 벨트**로 사령부(Command HQ)·저장고로 자동 이동한다.
- 화면에서 벨트 위 자원 덩어리가 움직이는 것이 보이게 한다(본진 블록 `blk_base_pad`에 벨트 길 자리 확보 필요 — 지금 본진 장식 표 `BlockKit.BaseDecor`와 겹치지 않게 설계).

## 2. 멀티 기지(외곽 자원지 M) 자원
- **사령부는 움직이지 않는다**(이전·재배치 없음).
- 플레이어는 외곽 자원지(공유 확장 부지)에 **정제·가공 공장**을 지어 자원을 캐고 "다듬는다".
- 다듬은 자원은 **자원 수송 트럭**(생산 유닛)이 공장 → 본진 사령부 하역장/컨베이어 입구로 실어 나른다.
- 맵 영향: 외곽 자원지 ↔ 본진 경사로 사이 길(간선 R·순환로)이 수송로가 된다. 트럭 정차·하역 자리를 본진 경사로 안쪽에 남겨 둘 것(현재 앞마당 확장 부지 `Forecourt (112,34)` 근처 검토).
- 기존 `NpcTraderSystem`·보급 트럭 교역 코드가 있으면 확장해서 쓴다(새 시스템 중복 금지, 38번 지시와 같음).

## 3. 유닛 다양성·가독성
- 진영 차별: 자유 연방(고가·고성능·공중) vs 대륙 연방(물량·저가)의 실루엣·색 차이가 게임 카메라(50~76m)에서 구분될 것.
- 수송·물류 역할 유닛(자원 수송 트럭 등)은 전투 유닛과 한눈에 다르게(짐칸·색 띠·아이콘).
- 맵 관문 승인 뒤 착수. 시가지 건물 높이(4~16m)에 유닛이 가려지지 않는지 함께 점검.
