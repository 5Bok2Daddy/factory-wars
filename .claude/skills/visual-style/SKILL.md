## 그림체 요약 (aow3-ref, LOOKDEV.md 결정값)

- 기본 프로필은 **A "AoW3 전장"**(`Resources/FactoryWars/Visual/VisualProfile`). 비교용 B(스타일라이즈드·외곽선)·C(성능 우선)는 `VisualProfile_B`·`_C`
- **정점 음영:** 정점 색 그라데이션(아래 어둡고 위 밝게) + 구운 AO(바닥 접촉부) + 부드러운 월드 좌표 색 노이즈. 팔레트 텍스처의 세로 줄이 밝기 단계이고, 메쉬를 만들 때 정점마다 V 좌표로 굽는다(`MeshKit.Shading`)
- **외곽선 없음**(A). 채도 강화·블룸 강화도 쓰지 않는다. 외곽선은 B 프로필에서만 쓴다
- 모서리 베벨은 목표 규칙이다(high 2단·medium 1단·low 없음). 아직 구현 전이다
- 따뜻한 오후 해(#FFF4E0, 고도 40°), 또렷한 해 그림자, 차가운 그늘
- 비율은 절제된 밀리터리 비율이다. 과장하지 않는다. 유닛 표시 배율 1.2, 건물 본체 78% + 콘크리트 바닥판·팀 색 줄
- **지형:** 통과 불가 지형은 층진 바위 절벽 대지, 강은 깊은 협곡, 맵 경계는 바위 절벽과 숲. 숲은 침엽수 위주에 단풍 포인트. 도시(도로·블록·폐허)와 자연을 섞는다. 높낮이는 화면에서만 만들고 판정은 `MapSpec` 그대로다
- **이펙트 순서:** 폭발 → 연기 기둥 → 잔불 → 그을음 데칼(크레이터)
- **팀 색 노출:** "중간"(포탑·패널 일부). 차체 대부분을 칠하지 않는다
- **외부 모델(항목 19B):** 자연물(나무·바위·절벽)과 도시 구조물은 Kenney CC0 모델 + 공용 셰이더 `FactoryWars/KenneyLit`(원래 색 × 틴트 × 높이 그라데이션 × 노이즈 × 접촉 AO)로 그린다. 매핑은 `KenneyAssetMap` 에셋에만 두고 파일 이름을 코드에 쓰지 않는다. **유닛은 절차 생성**이다. Kenney 외 출처는 쓰지 않는다

## 진영 형태 대비

색과 무관하게 형태로 구분한다.

- **자유 연방:** 돔, 납작한 반구, 원통, 곡면에 청록 발광 라인
- **대륙 연방:** 각진 상자, 경사 장갑, 리벳, 비늘 판, 망루, 깃발

## 색

- **팀 컬러는 포인트 패널 파츠에만 쓴다.** 나머지는 무채색 금속, 흙색, 국방색이다
- **발광은 기능별 고정색이다.** 진영과 무관하다
  - 전기: 청록
  - 쇳물, 포구 화염, 폭발: 주황
  - 경고: 적색. 주황은 쇳물과 화염 전용이다
- 정전이면 전기 발광은 꺼지고 쇳물은 어두워진다

## 메쉬 제작

- Unity 기본 Sphere·Capsule 대신 직접 만든 저면수 메쉬를 쓴다(면 노멀 + 정점 음영): 상자, 경사 상자, 모서리 깎은 상자, n각 원통·원뿔대, 원뿔, 반구, 회전체
- 움직이지 않는 파츠는 메쉬 하나로 합친다. 움직이는 파츠만 분리한다
- **메쉬는 서브메쉬 하나다.** 색, 팀 컬러, 발광, 금속감은 전부 팔레트 칸(`Swatch`)이다. 렌더러 하나가 그리기 호출 하나다
- 예외는 외곽선이다(B 프로필 전용). 켜면 유닛·건물이 뒷면을 바깥으로 늘린 외곽선 서브메쉬를 하나 더 가진다. 품질 낮음에서는 그리지 않는다
- 목표: 유닛 1기당 렌더러 2~4개, 건물 1채당 2~5개, 보병 분대는 메쉬 하나

## 이미지와 다르게 할 것

- **호크 공격헬기:** 실존 헬기와 다른 실루엣. 짧고 둥근 동체, 덕트형 꼬리 팬
- **스카이포트리스 폭격기:** 삼각 전익기
- **가공소 쇳물:** 주황
- **발전소 코어:** 청록
- **대륙 연방 깃발:** 새 기하 문양 SVG. 바탕은 팀 컬러
- **만리 다연장포:** 8륜
- **보병 수:** 레인저 4명, 스카이가드 3명, 민병대 2명, 화염방사 1~2명

## 복합 메쉬

기본 도형 1개짜리는 금지한다. 자식 메쉬 3~6개를 조합한다.

- **유닛:** 몸체 + 이동부(바퀴·궤도·다리, 공중은 회전익·날개) + 무기부(포탑·총열, 조준 회전과 사격 반동) + 진영 색 파츠
- **건물:** 기초 바닥판 + 본체 + 역할 상징물
  - 발전소: 냉각탑과 빛나는 코어
  - 가공소: 용광로와 컨베이어
  - 군수공장: 굴뚝과 크레인
  - 비행장: 활주로와 관제탑
  - 방어탑: 회전 포신
  - 전기 시설의 발광 파츠는 정전이면 꺼진다
- **철광산:** 크기·각도가 다른 어두운 바위 여러 개 + 금속 질감에 약하게 빛나는 광석 결정. 고갈되면 결정만 사라진다
- **숲:** 갈색 기둥 + 2~3단 잎 메쉬를 군집으로 배치한다. 채집하면 나무를 없애지 말고 그루터기나 잎이 적은 나무로 바꾼다. 숲은 끝까지 통과 불가이므로 빈틈처럼 보이면 안 된다
- **바위·언덕·협곡:** 높이와 회전이 다른 메쉬 조합, 바닥 색 차이. 변형값은 노드·지형 ID를 시드로 정해 모든 기기에서 같게 보이게 한다

## 머티리얼

- URP Lit의 Smoothness·Metallic·Emission을 칸별 맵으로 쓴다. 팔레트(`PaletteP0~7`, `PaletteNeutral`), 금속 맵(`PaletteSurface`), 발광 맵(`PaletteGlowOn/Off`)이다
- 머티리얼은 `ArtP{0~7}{On|Off}` 16개와 `ArtNeutral` 1개다. 전부 같은 셰이더 변형이어야 한다. 자원·지형은 `ArtNeutral`이다
- 코드로 만드는 머티리얼의 `globalIlluminationFlags`는 `RealtimeEmissive`로 둔다. `None`이면 URP가 `_EMISSION`을 지워서 발광이 조용히 사라진다
- 발광 맵 색은 바탕색보다 채도를 높게 둔다. 한 채널만 넘치면 주황은 노랑으로, 청록은 흰색으로 변한다
- 금속감은 금속 파츠에만 준다. 흙·고무·나무는 무광으로 둬서 재질 대비를 낸다
- 전기 시설, 포구 화염, 폭발에 발광을 쓴다. 레이저 무기는 이 게임에 없다

## 후처리

- 전투 씬의 Volume과 카메라는 `GraphicsQuality.Bind`가 맞춘다. 렌더러의 `postProcessData`가 비어 있으면 Volume이 조용히 무시된다
- `VolumeProfile` 컴포넌트는 `AddObjectToAsset`으로 저장한다. 빠뜨리면 다음 실행에서 사라진다
- 품질 설정은 낮음·보통·높음 3단계다. 단계별 값은 `FactoryWarsSetup.Tiers`에 있다. 낮음이 모바일 기준이고 Bloom·톤매핑·유닛 그림자를 끈다
- 렌더 타깃을 직접 주면 내부 색 버퍼가 그 형식을 따른다. HDR을 확인하려면 8비트가 아닌 대상에 그린다

## 성능

챕터 7 목표는 저사양 Android, 4인 대전, 유닛 400기, 30fps다.

- 머티리얼은 종류별로 공유한다. 진영 색은 공유 머티리얼로 처리하고, 인스턴스마다 머티리얼을 새로 만들지 않는다
- `MaterialPropertyBlock`을 붙인 렌더러는 SRP Batcher 호환에서 빠진다(Unity 6000.0 매뉴얼). 그래서 사용자 규칙의 두 선택지 중 공유 머티리얼을 쓴다
- 움직이지 않는 파츠는 생성할 때 메쉬를 합친다 (건물·지형·자원)
- SRP Batcher가 깨지지 않게 하고, 유닛 1기당 렌더러 수 상한을 정해 보고한다

## 표시 크기

- 유닛은 시뮬레이션보다 크게 그린다: 차량·공중 1.3배, 보병 분대 1.5배. 값은 `ArtRecipe.DisplayScale`이고 시뮬레이션은 바꾸지 않는다
- 화면 배치는 `ArtView`로 한다. 표시 배율은 모델에만 걸고, 선택 링과 체력바는 모델의 형제로 둔다
- 링 반지름과 바 높이는 프리팹을 구울 때 모델 크기로 정한다. 회전축은 모델 가운데다

## 결정론

- 그래픽·연출 코드는 View에만 둔다
- 시뮬레이션 코드는 바꾸지 않고, 필요한 정보(조준 대상, 사격, 정전)는 기존 상태와 이벤트를 읽어서 쓴다
- 꼭 시뮬레이션에 이벤트를 추가해야 하면 승인을 요청한다

## 아이콘

- 철·목재·강철·전기·인구 자원 아이콘, 건물·유닛 대표 아이콘, 진영 마크를 SVG로 직접 그린다
- 원본은 `Art/Icons/src`에 두고, PNG 스프라이트로 변환해 HUD와 패널에 쓴다
- 변환은 관리자 권한 없이 되는 방법으로 한다

## 가상 진영 원칙

진영 마크와 무늬는 새로 디자인한다. 실존 국기·휘장·문자·무기 상표와 닮게 만들지 않는다.

## 교체 가능 구조

유닛·건물 ID마다 프리팹을 갈아끼울 수 있게 한다. 챕터 6에서 구매 에셋을 쓰면 그 ID만 바꾸면 되게 한다.
